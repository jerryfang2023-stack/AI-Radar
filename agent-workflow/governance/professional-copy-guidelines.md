# 专业领域文案规范

状态：现行；更新：2026-09-13。依据用户长期要求明确：专业领域的文案必须使用准确、专业且便于理解的表达。

## 适用范围

凡观澜 AI 文案涉及营销、管理、组织行为、投资、战略、财务、人力资源、经济学及其他专业领域，均适用本规范。覆盖网站、小程序、运营后台、报告、文章、社交内容、演示稿和设计物料；不因文案较短或用于营销而降低准确性要求。

本文件是上述表达要求的唯一规则源。页面任务另按 [Copy-first](copy-first-page-gate.md) 形成文案表；非页面文案沿用所属内容流程，不因此启动页面构建或发布。

## 表达要求

1. **专业准确**：使用对应领域通行且适合当前语境的术语，明确概念、主体、行为和结果；同一概念全文统一命名。不能用自创词、模糊口号或泛化比喻代替专业概念。
2. **便于理解**：根据目标读者选择解释深度。专业术语有助于准确表达时保留；首次出现且读者可能不熟悉时，用一句简短说明解释。常见词无需机械加注，不堆砌术语，不写成教科书。
3. **具体清晰**：优先说明谁采取什么行动、影响什么指标或结果。减少“赋能、抓手、底层逻辑”等没有具体所指的表达；必须说清其实际含义。
4. **概念不混用**：例如收入与利润、融资金额与估值、市场规模与企业收入、岗位职责与绩效目标，应按材料中的真实含义分别表达。不能仅为让句子显得专业而替换成含义不同的词。
5. **证据边界**：保留原始材料的时间、对象、指标口径及不确定性。区分事实、来源观点与编辑分析；没有依据时不能补出因果关系、投资结论、财务预测或效果承诺。
6. **符合用途**：事实页准确呈现事实，操作界面帮助完成任务；只有内容契约允许的分析文章或报告才表达有依据的判断。营销文案可以强调价值，但不能用夸张效果或保证性收益替代证据。
7. **原文保真**：引号内原话保持原貌；需要专业化整理时放在引文外，并区分原话与编辑表述，不把改写伪装成原话。

## 改写示例

下列仅示范表达方式；必须先核实实际含义，不能将示例中的结论直接套到业务材料。

| 原表述 | 已确认对应含义后可改为 | 核验重点 |
|---|---|---|
| 把用户牢牢抓住 | 提高客户留存率 | 实际谈的是留存、复购还是使用频率 |
| 把组织拧成一股绳 | 明确共同目标、职责分工与协作机制 | 材料是否说明了这些具体措施 |
| 公司越来越值钱 | 企业估值上升 | 是否有估值依据，不能由融资金额直接推断 |
| 生意做大了，赚得更多 | 分别说明营业收入与利润的变化 | 不能把收入增长等同于利润增长 |
| 把人放到合适的位置 | 根据岗位要求与人员能力进行岗位匹配 | 是否实际涉及岗位配置，避免擅自引入绩效结论 |

## 写作与验收

写作前确认读者、领域和文案用途。涉及关键专业概念时，在已有文案表或审校记录中注明“术语与通俗解释”；无须为每句话单独建表。含义不确定的概念先核对原始材料，必要时查权威定义；无法确认时保留不确定性，不能自造解释。

交付时核对：术语准确且一致、必要解释充分、表达具体、事实与判断分开、原话未被改写、读者能理解。术语误用、黑话堆砌、以比喻替代概念或新增无依据的结论，均须修正后再交付。关键词扫描只能辅助定位，不能替代语义审校。
