## 规则与代码根因、针对性修复

1. **生产环境与测试夹具串用。** 测试显式绑定自己的私有证据目录；新增 Linux/Windows 生产代码检查，模拟外置私有证据路径且不读取真实秘密。同步运营页版本/退役页面预期。PR #798。
2. **恢复边界错误。** 已验收采集因下游失败被重采/重复模型生成；失败恢复未证明私有原文已归档。恢复现在要求同日期、正确流程、成功的原文归档及采集或恢复步骤，支持已归档的失败恢复链；保留模型候选并重新过门禁，不覆盖已接受 intake 原始标题。PR #799 / #801。
3. **监督器资源与状态错误。** 子进程输出超过同步缓冲导致 ENOBUFS，父子超时不一致；旧 repair worktree 和失配的运行态报告被当作当前真相。完整日志外置、内存只保留有界尾部，内外超时协调；repair worktree 仅在干净且可快进时同步；报告绑定 Git 与当天完整数据指纹。PR #800。
4. **目录准入与覆盖门禁口径不同。** 前台仅接受有审核归属的企业/产品，覆盖门禁却把未审核实体也加入必达分母。共用经审核的准入集合和合并解析；未审核候选继续显示待审，不自动批准；已批准实体、事件、引用和 mentions 缺失仍阻断。PR #800。
5. **跨日期标题元数据混用。** 相同内容哈希/URL 的前一日中文记录被用来判断当日英文翻译方式。定位同时约束原始标题、内容哈希、来源 URL，优先同日；私有记录写入还必须匹配日期，不能写入跨日 fallback 原文。PR #801。
6. **发布成功定义不完整。** Pages 被更新部署替代后会误报失败；独立融资站无文件变化时会跳过线上核验。Pages 只接受目标提交或证明为其后代的成功部署；状态为 awaiting_portal，不能代表融资网站已发布。融资站无变更仍读回线上；公有/受保护发布回执必须同一完整提交与 release ID，漂移则原子重部署。WaveSight PR #800、Funding Portal PR #7。
7. **融资金额语义漏检。** 中文后置“融资”使用拉丁字词边界导致漏识别；“融资将估值推高至”被当作融资额。修复抽取，并在事件—卡片一致性与融资引用校验中拒绝估值冒充融资额；覆盖单实体及多实体场景。PR #802。
