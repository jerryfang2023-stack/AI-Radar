## Scope

This release closes the large repository, Vault, evidence, data-lake, and Windows automation adjustment:

- the independent `观澜AI` Vault is the only active Obsidian knowledge projection;
- Data Lake V4 is constrained to the exact 23-table contract;
- original-source locators and citation cards are projected into the Vault;
- original-body snapshots are backed up to a separate private repository;
- Windows automation is converged to seven scheduled tasks;
- Hermes watchdog and heartbeat publication run as one observable cycle;
- current documentation and version contracts describe only the active V4 operating model.

## Specification Audit

### Fixed

- The Vault gate now detects a surviving sibling `AI热点` directory or Obsidian registration.
- Vault evidence metadata now states the actual storage model:
  `repository_snapshot_plus_private_backup`.
- Historical V3 reports remain historical evidence and are not active production routes.
- Data Center and Application Center remain separated in the generated Vault contract.

### Remaining Release Risk

The public Git repository still contains historical original-body snapshots. The new private
evidence repository is a verified backup, not yet the exclusive source store. Removing those
objects from the public repository and its Git history is a separate destructive migration that
requires explicit authorization, remote visibility review, consumer migration, and rollback
planning. This release does not claim that private storage is exclusive.
