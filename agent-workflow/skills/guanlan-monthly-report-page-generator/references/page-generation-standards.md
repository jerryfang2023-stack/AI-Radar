# Monthly Report Publication Standards

- Canonical content stays in complete accepted WaveSight Markdown.
- Stable ID is `monthly-${month}`.
- WaveSight writes redirects only; the AI financing site owns metadata, complete body, archive, navigation, and reading UI.
- Dynamic discovery replaces manually maintained report lists.
- Publication requires title, summary, date, type, body, unique ID, metadata/body parity, and non-regressing inventory/date.
- Live verification compares report count, newest report ID, and report body count after atomic deployment.
- Current versions are `SITE-V4.6.1-research-retirement` and `REPORTS-V1.3.0-funding-portal`.
