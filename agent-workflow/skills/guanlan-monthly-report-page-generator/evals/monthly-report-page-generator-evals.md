2. Pass when the portal body preserves the complete accepted Markdown argument after frontmatter and internal evidence-marker cleanup.

4. Pass when report removal, newest-date regression, duplicate IDs, and missing bodies fail closed.
5. Pass when the report archive and old Guanlan Research route target `https://www.zkdlj.vip/#reports` without duplicate local content.
6. Pass when Opportunity Map failure cannot block monthly acceptance or financing-site publication.
7. Fail if WaveSight recreates a monthly reader, styled local table, report archive, selector, or Guanlan Research navigation.
