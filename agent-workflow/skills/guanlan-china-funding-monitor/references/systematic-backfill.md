# Systematic historical funding

1. Resolve the user-authorized start/end dates. Enumerate publisher investment-index pages until an older-than-start boundary is observed (`collect-china-funding-index.mjs`); preserve successful page checkpoints. A page failure or arbitrary page cap cannot establish coverage. Keep each company/round/date row as a discovery hint, excluding generated index summaries from facts.
2. Cross-check the monthly search inventory and perform company/round-specific original-report discovery (`search-china-funding-cases.mjs`). Reuse successful queries; retry only failures with the configured alternative provider. Record provider outages and earlier failed attempts; never buy credits automatically. Supplemental original publishers can be recovered from completed queries with `expand-china-funding-secondary-sources.mjs`.
3. Run the historical pipeline with `--append-new-sources=true`. Reuse immutable accepted evidence and existing private originals, capture only new URLs, and record a separate source-stage repair for unreadable originals. Targeted financing titles need not contain “AI”; the original body decides industry admission. Verify publisher body boundaries and explicit publication stamps before extraction.
4. Repair missing publication dates through `repair-china-funding-source-dates.mjs`: retain the immutable original body and record explicit publisher publication metadata separately. Never use modified dates, URL dates or capture time. Rebuild, then use the authorized historical extraction adapter on every eligible unprocessed original, preserving each accepted output. Exact spans, protected amounts, actual recipient identity, single-round boundaries and original dates remain mandatory. Different companies must not merge because of a common investor or amount. Keep old published identities stable; new historical grouping belongs to the explicit source whitelist.
5. Generate Funding Insights through its owning Skill. Search missing amount/round/investor/product/company fields against captured announcements and secondary originals. Chinese company names require Chinese queries and Chinese financing/product relevance terms even when CN geography is still unverified; query language never establishes geography. Resolve descriptive headline subjects against accepted original quotes before searching. Distinguish explicitly undisclosed fields, failed searches, contradictory sources and unattempted work. Do not convert a multi-round cumulative total into a single financing.
6. Rebuild `build-china-funding-history-quality.mjs` and OPS. Reconcile each index case with actual subject, date and event references. Another round's card for the same company does not close the case. Keep unresolved and out-of-scope cases explicit after secondary research. Search counts and candidate counts are not verified-event counts.

   Before publication, compare same-company/round/amount cards across distant dates. Identical original announcements republished months later require an explicit same-disclosure review. Link their application `source_event_ids`, retain both original canonical dates, and let the card aggregate select the earliest disclosure. Similar amounts or round labels alone never justify merging.

   Include legal-name/brand variants, adjacent publication dates and rounded/cross-currency amount descriptions in that review. Explicitly reviewed event links may join those variants while retaining each original disclosure; unlinked variants must remain separate. An original announcement date stated in the body takes precedence over capture time. Record the source quote and date correction, preserving the publisher's disclosure timestamp separately.

   Historical publication completeness is limited to the authorized CN application scope. Report unknown or outside-CN cases separately; all eligible domestic cases still require the full card evidence and coverage gates.
7. Finish publication through canonical/entity/institution/card gates, committed private evidence, public Git, Pages, Funding Portal/Mini Program and authenticated OPS delivery. Report new versus existing/updated cards, monthly coverage, exclusions and remaining evidence gaps separately. Never call an unprocessed extraction or card queue complete.
