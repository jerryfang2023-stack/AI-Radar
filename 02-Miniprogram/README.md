# 观澜融资情报站微信小程序

基于 V0.5.5 的原生微信小程序。

## 已实现

- 融资情报：搜索、时间/地区/轮次/市场筛选、排序、紧凑视图；
- 融资详情：融资事实、公司介绍、投资方、信号、风险、历史轮次和证据来源；
- 商业观察：当前社群精华、周报、月报及往期内容；社群精华为编辑确认后的重写文章；
- 公司比较：支持选择 2–3 家公司并复制导出摘要；
- 生态图谱：整合企业库、投资机构库与核心人物库，并提供独立主体档案；
- 我的：统一积分、8 级会员成长、积分兑换会员权益、社群状态和原生社群申请。

## 打开方式

1. 运行 `npm run verify`；
2. 在微信开发者工具中导入本目录；
3. 项目使用生产 AppID `wx34133741173154d4`，可真机预览和上传开发版。

## 数据更新

```text
npm run build:data
```

数据脚本从现有 Funding Insights 前台投影生成小程序专用的精简列表和详情数据，不修改上游数据。

小程序 V0.5.5 使用双通道数据：安装包内数据用于离线兜底，联网时从
`https://www.zkdlj.vip/data/` 拉取已通过融资站发布门禁的融资卡、周报和月报。
因此观澜监测任务完成并发布融资站后，小程序无需重新发版即可读取新内容；新客户端
版本仍会刷新内置兜底数据。

正式发布前需在微信公众平台将 `https://www.zkdlj.vip` 配置为 request 合法域名。

## 社群与积分

- 用户授权手机号后，由账号服务向现有社群会员库核验，命中现有会员时直接关联，不重复注册。
- 社群历史积分按 1:1 全量计入可用积分和累计成长积分；后续变动按差额同步。
- 成长等级为 8 级：初识者、观察者、研究者、洞察者、实践者、共建者、引领者、领航者。
- 300 分兑换 7 天会员权益，1000 分兑换 30 天会员权益；兑换扣可用积分，不扣累计成长积分。
- 未入群用户在小程序内提交申请，审核结果回显在“我的”，不跳转 H5。
