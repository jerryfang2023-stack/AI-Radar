# 观澜融资情报站微信小程序

方案 2「掌上融资情报」的原生微信小程序 MVP。

## 已实现

- 融资情报：搜索、时间/地区/轮次/市场筛选、排序、紧凑视图；
- 融资详情：融资事实、公司介绍、投资方、信号、风险、历史轮次和证据来源；
- 观察列表：本地收藏；
- 公司比较：支持选择 2–3 家公司并复制导出摘要；
- 市场概览：发布量、证据覆盖、市场类别和轮次分布；
- 我的：数据版本、使用说明和本地数据管理。

## 打开方式

1. 运行 `npm run verify`；
2. 在微信开发者工具中导入本目录；
3. 当前使用微信测试 AppID，可真机预览；正式发布前替换为已认证小程序 AppID。

## 数据更新

```text
npm run build:data
```

数据脚本从现有 Funding Insights 前台投影生成小程序专用的精简列表和详情数据，不修改上游数据。
