## 数据更新

```text
npm run build:data
```

数据脚本从现有 Funding Insights 前台投影生成小程序专用的精简列表和详情数据，不修改上游数据。

小程序 V0.9.0 使用双通道数据：安装包内数据用于离线兜底，联网时先读取
`https://www.zkdlj.vip/data/mini/` 的版本清单与轻量索引；融资详情、社群精华公开正文按 ID 加载，
周报/月报正文仍由统一权限接口返回，主体关系数据仅在生态详情使用时加载，并将通过校验的版本保存在本地。
因此观澜监测任务完成并发布融资站后，小程序无需重新发版即可读取新内容；新客户端
版本仍会刷新内置兜底数据。

正式发布前需在微信公众平台将 `https://www.zkdlj.vip` 配置为 request 合法域名。

## 社群与积分

- 用户授权手机号后，由账号服务向现有社群会员库核验，命中现有会员时直接关联，不重复注册。
- 社群历史积分按 1:1 全量计入可用积分和累计成长积分；后续变动按差额同步。
- 成长等级为 8 级：初识者、观察者、研究者、洞察者、实践者、共建者、引领者、领航者。
- 300 分兑换 7 天会员权益，1000 分兑换 30 天会员权益；兑换扣可用积分，不扣累计成长积分。
- 未入群用户在小程序内提交申请，审核结果回显在“我的”，不跳转 H5。
- 社群首页对所有用户开放；只有进入子栏目详情、查看成员档案或参与互动时才提示申请加入。
- 角色图谱从受限接口读取成员同意公开的字段，正式成员名单以服务端当前状态为准；手机号、微信号和内部审核信息不进入公开目录，完整档案不作为静态离线副本打包。
- 申请资料中的公开字段会保存到“我的档案”，成员可二次修改；联系方式继续由账号服务独立处理。
