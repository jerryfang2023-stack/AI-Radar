## 当前功能

- **融资**：融资精选最多三卡滑动，达标不足不凑数；公司／机构／产品搜索、全球／中国及子赛道筛选。同一已核验企业一张卡，详情保留历史轮次、投资方观点、产品与客户、风险和来源。
- **生态**：生态图谱与生态名录。图谱覆盖 7 大赛道和 45 子赛道的热力及趋势；名录包含公司、产品、投资机构、人物。中国企业标题使用已核验简称，原名和稳定身份继续用于查询和关联。
- **社群**：分享实录、成员图谱、赛季积分与 Token 权益等现有入口；悬赏令已移除。阅读权限与融资、生态统一，入群申请审核不是内容浏览条件。
- **我的**：个人资料、收藏与关注、签到／阅读／收藏／邀请成长任务及 7／30 天权益兑换。好友首次有效注册奖励 300 积分。
- **账户**：小程序与 PC 共用服务端账号和阅读权益。微信昵称需主动选择或填写，手机号授权不会自动返回昵称；注册读取最终失焦值并等待支持的原生昵称校验。

## 开发与验证

在本目录运行 `npm run verify`（数据生成、测试、项目校验），再由微信开发者工具导入本目录。基础库及 AppID 使用 `project.config.json`；不保存 AppSecret。版本使用 `1.2.9 → 1.3.0` 的进位规则，package.json、遥测版本与上传版本必须一致。

本机或模拟测试不替代真机体验。1.2.4 引入的原生微信昵称选择行为仍待真机确认；已有 wxid 昵称不根据猜测替换，可在个人资料中修改。

## 数据与权限边界

包内索引为已审核数据的离线兜底；联网从 `https://www.zkdlj.vip/data/mini/` 检查版本。普通内容更新由网站发布链同步，无需每次上传客户端；新增交互、样式或客户端契约变更需要上传。

1.2.5 使用 `cards` 展示企业主体，使用 `events` 计算融资事件热度，`cardAliases` 兼容旧卡链接。2026-10-02 上传时为 509 张主体卡、542 条独立融资事件；它们是该版本快照，不是永久总数。不能将旧的按事件分卡数据重新打进新版。

未注册用户沿用公开预览和主动注册流程；已登录且有有效阅读权益的用户可阅读社群内容。社群本人档案修改、奖励归属和非公开联系方式仍受独立身份核验保护。社群入群申请是微信群审核流程，不能用作阅读门槛；旧 `community-apply` 客户端路由当前仅跳转社群首页，不代表已恢复原生申请表。

手机号只在服务端核验，持久化为 HMAC 和脱敏值。昵称候选不能直接授予他人社群身份。定向内测或社群运营授权以服务器审计流水为准，不改变默认会员方案。
