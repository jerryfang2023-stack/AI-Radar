# 观澜融资情报站微信小程序

基于 V0.5.8 兼容基线形成的 V0.6.8 原生微信小程序。

## 版本脉络

- V0.5.0：融资情报、生态图谱、商业观察和“我的”四个核心栏目基线；
- V0.5.5：打通社群会员、统一积分、会员权益兑换、社群申请与社群精华；
- V0.5.6：融资情报公开字段中文化，并加固融资数据接入与发布校验；
- V0.5.7：恢复 V0.5 融资卡、摘要卡和底部导航布局，补齐账号关联及离线积分同步；
- V0.5.8：合并 V0.5.6 中文化成果与 V0.5.7 兼容修复；
- V0.6.0：接入微信虚拟支付道具直购，保留三档一次性会员权益，并支持购买后 15 天内全额退款；
- V0.6.1：融资默认先展示全球，中国列表去除重复地区标识，人民币金额在数据源、PC 数据中心和小程序统一以“元”展示，并收紧底部导航留白。
- V0.6.2：将底部安全区纳入四个导航按钮，导航背景、选中态和点击区域贴合屏幕底边；社群积分由会员服务按已发布期次持续同步。
- V0.6.3：生态图谱搜索栏移至企业库、机构库、人物库切换栏上方，筛选逻辑和列表结构保持不变。
- V0.6.4：融资顶部统计卡对齐生态图谱“商业主体全景”样式，统一标题层级、数字字重、标签位置、分隔线和留白。
- V0.6.5：接入匿名运营监测，记录页面访问、访问会话、搜索、内容阅读及注册/支付转化；经营结果以服务端注册、订单和退款记录为准。
- V0.6.6：确认三个会员道具已在虚拟支付现网发布，补齐 iOS App Store 退款问询响应，并保留官方 `wx.requestVirtualPayment` 全终端购买链路。
- V0.6.7：登录规范修复开发版验证，未提交审核，已由 V0.6.8 替代。
- V0.6.8：从分享链接进入的融资、生态主体与观察详情可完整阅读；进入关联详情、其他栏目或使用收藏、比较等个人权益时，由用户自主选择注册登录。普通小程序内的付费详情入口继续执行会员访问控制。

## 已实现

- 融资情报：搜索、时间/地区/轮次/市场筛选、排序、紧凑视图；
- 融资详情：融资事实、公司介绍、投资方、信号、风险、历史轮次和证据来源；
- 商业观察：当前社群精华、周报、月报及往期内容；社群精华为编辑确认后的重写文章；
- 公司比较：支持选择 2–3 家公司并复制导出摘要；
- 生态图谱：整合企业库、投资机构库与核心人物库，并提供独立主体档案；
- 我的：统一积分、8 级会员成长、积分兑换会员权益、社群状态和原生社群申请。
- 会员购买：30 元/30 天、168 元/180 天、300 元/365 天，均不自动续费；支付结果由服务端向微信确认后生效。

## 打开方式

1. 运行 `npm run verify`；
2. 在微信开发者工具中导入本目录；
3. 项目使用生产 AppID `wx34133741173154d4`，可真机预览和上传开发版。

## 数据更新

```text
npm run build:data
```

数据脚本从现有 Funding Insights 前台投影生成小程序专用的精简列表和详情数据，不修改上游数据。

小程序 V0.6.8 使用双通道数据：安装包内数据用于离线兜底，联网时从
`https://www.zkdlj.vip/data/` 拉取已通过融资站发布门禁的融资卡、周报和月报。
因此观澜监测任务完成并发布融资站后，小程序无需重新发版即可读取新内容；新客户端
版本仍会刷新内置兜底数据。

正式发布前需在微信公众平台将 `https://www.zkdlj.vip` 配置为 request 合法域名。

## 社群与积分

- 用户授权手机号后，由账号服务向现有社群会员库核验，命中现有会员时直接关联，不重复注册。
- 社群历史积分按 1:1 全量计入可用积分和累计成长积分；后续变动按差额同步。
- 成长等级为 8 级：初识者、观察者、研究者、洞察者、实践者、共建者、引领者、领航者。
- 300 分兑换 7 天会员权益，1000 分兑换 30 天会员权益；兑换扣可用积分，不扣累计成长积分。
- 未入群用户在小程序内提交申请，审核结果回显在“我的”，不跳转 H5。
