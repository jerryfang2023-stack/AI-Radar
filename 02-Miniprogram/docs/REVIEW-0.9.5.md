# 观澜 AI 0.9.5 审核与验收说明

## 审核语

完善小程序页面分享能力，社群分享实录、悬赏令、积分榜、角色图谱及其他栏目均支持微信好友转发和朋友圈分享；修复人物、机构档案进入关联企业时提示“主体档案不存在”的跳转问题；修复个人资料页首次授权手机号无法完成绑定的问题。已审核社群成员首次注册或绑定核验手机号后，可自动同步社群资料、积分与社群权限，并获得 90 天小程序使用权限，无需重复申请入群。会员库未登记手机号时，现有微信昵称仅生成待人工确认的资料认领，管理员在运营后台确认后自动同步，昵称本身不会直接获得权限。保持现有页面样式和支付规则不变，不新增资料采集字段或支付功能。

## 重点验收

1. 进入社群的分享实录、悬赏令、积分榜、角色图谱及详情页，右上角菜单可转发给好友并分享到朋友圈。
2. 从分享卡片进入实录、悬赏详情或角色档案，路由参数正确；未登录用户仍按原会员权限提示。
3. 在融资案例关联的人物或机构档案中点击“查看企业”，可进入对应企业档案，不再提示主体不存在。
4. 融资、生态、社群、我的及其余页面均可唤起分享；档案编辑、设置等私密页面分享公共首页，不包含私密参数。
5. 在无本地账号令牌时从“个人资料”授权手机号，可直接完成首次登录和绑定，不再重复提示授权。
6. 已审核社群成员以社群登记手机号首次注册或绑定后，状态为“已入群”，社群资料及积分同步，获得一次性 90 天小程序使用期；重复操作不会重复延长。
7. 社群会员库没有手机号但微信昵称形成候选时，账号显示“资料认领审核中”；运营后台确认对应成员后，再次进入页面会自动变为“已入群”，无需重新申请或发布小程序。
8. 普通新用户仍为 7 天体验，现有页面布局、导航和支付规则保持不变。

提交审核及正式发布仍由负责人在微信后台操作。
