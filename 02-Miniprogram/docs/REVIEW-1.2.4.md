# 小程序 1.2.4 审核说明

## 简略版

修复注册时选择微信昵称后未正确保存、可能提交旧昵称的问题，完善昵称校验及重复提交处理，优化注册体验。

## 连同 1.2.1—1.2.3 合并提交

优化生态图谱、企业及机构档案和个人中心展示；统一社群与其他栏目浏览权限；修复已登录用户提示注册、图表弹层重叠及注册昵称保存问题，提升浏览和注册体验。

## 验收路径

1. 游客进入「我的」并主动打开注册弹窗，选择头像；点击昵称框并选用微信昵称，结束输入。昵称确认通过后授权手机号，注册完成后「我的」和后台显示服务器确认的昵称。
2. 输入旧昵称后改选微信昵称，应保存新选择；不再提交旧值。
3. 昵称校验失败或超时时提示重新选择，不能提交未经确认的昵称；取消手机号授权后可重试，重复点击不会重复提交。
4. 已有社群成员可继续通过授权手机号同步已有身份，无需重复填写姓名。已有账号的登录和会员权限不变。

手机号授权不包含自动获取微信昵称；昵称仍由用户主动选择或填写。历史 wxid 昵称不猜测替换，可在「我的—个人资料」修改。
