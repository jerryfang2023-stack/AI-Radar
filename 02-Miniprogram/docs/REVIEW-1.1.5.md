# 1.1.5 融资首页精选卡片

审核说明（可直接填写）：
本次优化融资首页展示，将原统计卡片升级为紧凑的“今日融资精选”，集中展示公司/产品、融资金额、轮次、赛道与简要融资观察。支持左右滑动与点击查看详情，切换中国/全球时同步更新。无当日融资时明确标注最近披露日期，保留原有搜索、分类筛选及融资列表。

体验路径：打开小程序 → 融资首页 → 左右滑动精选卡片 → 点击卡片查看详情 → 返回后切换中国/全球、搜索及分类。
首页与精选不要求登录；详情沿用已有游客试读及会员权限。注册、社群与支付流程未变。

数据取自审核后的公开融资索引，排除隐藏及机器人系统记录。观察由已披露赛道与投资方事实组成，不推断收益或资本趋势。没有可展示数据时显示空态，不使用 Demo 样例。上传不等于提交审核或发布，由管理员提交审核。
