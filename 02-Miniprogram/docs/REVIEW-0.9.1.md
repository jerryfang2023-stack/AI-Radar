# 微信小程序 V0.9.1 审核说明

## 可复制的版本说明

优化社群首页，突出分享实录、悬赏令和成员行业图谱；新增完整实录阅读、全员积分榜与规则、通讯录及可修改的个人档案，补充成员分享证据资料。行业观察整合至生态栏目。

## 可复制的审核备注

底部“社群”首页开放浏览，显示分享实录、悬赏令与成员摘要，不展示首页排期或积分条。用户主动进入受限详情时提示申请加入；已入群用户可查看完整实录、排期、积分榜、行业图谱与通讯录，并编辑“我的档案”。悬赏问题和回答经后台人工审核后展示，结算由发起人按规则分配站内积分，不能重复发放。积分不可充值、提现或转让，不涉及现金悬赏。手机号、微信号和内部审核信息不公开。

首页仅在存在已发布悬赏令时显示悬赏模块；没有内容时完全隐藏空卡与引导文案，顶部“悬赏令”入口保留。

## 验证路径

1. 社群首页 → 造浪者计划 → 实录列表 → 任一期 → 嘉宾全文；排期位于造浪者计划内。
2. 社群 → 悬赏令 → 发起问题 / 回答 / 参与；内容审核由现有会员管理后台处理，不在用户端提供审核按钮。
3. 社群 → 积分榜 → 积分规则 / 我的积分详情。
4. 社群 → 行业图谱 → 通讯录 → 成员 → 行业角色与分享证据 → 来源实录。
5. 行业图谱 → 我的档案 → 编辑资料 → 保存；另一设备重新进入可读取更新，版本冲突提示刷新。
6. 生态 → 行业观察 → 周报 / 月报 / 社群精华。

受限流程需要已审核、正式入群且与已核验手机号关联的账号。提交审核时请提供真实可用的测试条件，不伪造通用账号或绕过身份校验。后台开发版上传不等于审核或正式发布，提交审核由负责人完成。

## 数据边界

个人档案区分成员自填资料和依据分享整理的行业角色，编辑自填资料不会覆盖证据。角色来源为社群内部资料，仅对授权成员展示；私密 PDF、导入清单及完整分享正文不进入小程序静态包或公开 Git。

原备案草稿 `filing-text-package.md` 的“无用户发布内容”已不适用于新增悬赏问答，不应直接复用。审核说明及后台填写应如实包括受限社群内的人工审核问答功能。
