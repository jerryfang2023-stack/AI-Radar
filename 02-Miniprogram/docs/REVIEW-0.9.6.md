# 观澜 AI 0.9.6 审核与验收说明

## 审核备注（可直接复制）

本版本新增社群赛季积分与 Token 权益展示。社群成员可在“社群—积分榜”切换总积分、第一季和第二季，并查看对应积分明细；在“社群—Token 权益”查看本季激励池额度、赞助商、分配规则、本人的赛季积分及奖励发放状态。奖励按后台公布的赛季规则结算，领取奖励不扣减社群积分；当前页面仅展示奖励信息，不提供 Token 购买、充值、转账、交易、提现或在线领取功能，不新增支付接口。社群首页隐藏悬赏入口，保留分享实录及角色图谱。受限内容继续校验真实社群成员身份，不公开成员联系方式或内部审核信息。

## 本次主要更新

- 积分榜增加总积分、第二季、第一季切换；积分明细与分享链接保留所选赛季。
- 新增独立 Token 权益页，读取运营后台已公布的激励池与个人奖励状态；规则可展开查看。
- 赛季积分用于社群排名与奖励计算，与小程序钱包余额分开展示；此版本不改动历史钱包或会员支付规则。
- 社群首页隐藏悬赏导航及卡片，历史悬赏页面及服务仍保留，不应在材料中声称悬赏功能已完全删除。
- 延续 0.9.5 的原生分享、关联企业跳转、手机号绑定与已审核成员身份同步。

## 审核路径

1. 底部“社群”→“积分榜”：切换总积分、第二季、第一季，打开积分明细及积分规则。
2. 底部“社群”→“Token 权益”：查看额度、赞助商、“我的奖励”，展开“激励规则”。页面支持下拉刷新后台配置。
3. 第二季尚未产生有效积分或尚未确认分配时，个人奖励应显示“待结算”，已分配额度显示“—”；不得将激励池总额解释为个人已到账额度。
4. 未入群账号进入受限功能时显示申请加入提示；已审核入群且完成真实账号关联的成员可查看完整页面。
5. 回归“社群—造浪者计划／分享实录／角色图谱”及“我的—个人资料”，核对原有导航、资料、分享与身份同步。

受限流程需要真实可用的已关联社群成员测试身份，由负责人通过微信审核后台提供测试条件。无通用测试密码；不得绕过成员校验或将演示账号作为真实账号。开发版上传、提交审核与正式发布是三个独立步骤，上传回执另见对应发布记录。

## 当前后台配置参考

2026-09-10 已核验：第二季激励池 100000000 Token，赞助商“观澜AI”，按赛季总积分分配；计分期间为 2026-09-14 至 2026-10-10（含开始日，不含结束日）。配置由后台管理，可在上传后变化，不写死在客户端。个人额度按比例向下取整，余量保留在池中；管理员确认分配后锁定，再单独登记实际发放凭据。

当前版本未提供 Token 使用平台入口、兑换码领取或自动发放能力，不在审核说明中承诺此类功能。
