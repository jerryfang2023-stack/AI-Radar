## 审核备注（可直接复制）

底部栏目为“融资、生态、社群、我的”。社群首页开放浏览，显示编辑推荐、往期分享实录和成员摘要；仅在存在已发布悬赏时显示悬赏模块，首页不显示排期及个人积分。

用户主动进入社群子栏目或详情时，按成员身份开放内容或提示申请加入。已审核、正式入群并完成账号关联的成员可查看分享排期、完整实录、积分榜与规则、角色图谱、通讯录，并修改“我的档案”。档案将成员自填资料与编辑整理的分享证据分开保存，修改自填资料不会覆盖证据内容。

悬赏问题和回答经后台人工审核后展示，发起人按规则分配站内积分，结算防止重复发放。积分不可充值、提现、转让或交易，不涉及现金悬赏；社群积分榜保留正常活动积分，排除管理权限授分。

“生态—行业观察”提供周报、月报和社群精华。本次增加本地摘要缓存、会话内复用与后台刷新，保留服务端身份校验。成员联系方式、内部审核资料及完整分享正文不进入公开数据包，受限档案和实录仍需通过成员权限访问。

## 审核操作路径

1. **公开首页**：底部“社群” → 编辑推荐与往期实录；推荐之外最多四篇实录，每篇独占一行，数量不足时按实际内容展示。无已发布悬赏时模块隐藏，但“悬赏令”导航入口保留。
2. **非成员申请**：未入群账号主动点击社群子栏目或详情 → 申请加入提示 → 原生申请表。仅浏览首页不会自动弹出申请。
3. **分享内容**：社群 → 造浪者计划 → 分享排期 / 分享实录 → 具体期次与嘉宾全文。
4. **悬赏互动**：社群 → 悬赏令 → 发起问题 / 回答 / 参与。审核由后台管理员处理，用户端不提供审核按钮；没有已发布内容时可以验证空列表。
5. **积分**：社群 → 积分榜 → 积分规则 / 我的积分详情。按全员真实积分排序，管理权限授分不进入榜单或其明细；原钱包与管理权限不变。
6. **成员资料**：社群 → 角色图谱 → 分类名单 / 通讯录 → 成员档案 → 分享证据 → 来源实录。分类按当前公开成员人数降序，离群成员不进入展示。
7. **修改档案**：角色图谱 → 我的档案 → 编辑 → 保存；保存同步服务端，跨设备修改冲突会提示刷新。
8. **生态观察**：生态 → 行业观察 → 周报 / 月报 / 社群精华。
9. **切换体验**：社群与其他底栏切换、反复进入社群列表；缓存有效时复用内容，刷新不重复展示全页加载文字。首次无缓存、受限全文和档案仍需联网。
