# 1.1.3 登录与手机号绑定修复

修复个人资料页首次绑定未携带已填写昵称、头像状态导致重复注册提示的问题。手机号绑定成功同步服务端会员、积分和社群状态；有效登录结果不会因尚未入群被再次判定为注册失败。

服务端改用微信 stable_token，普通获取不强制刷新；对明确的 40001、40014、42001 凭证失效错误重新获取并最多重试一次手机号交换。手机号授权码错误与网络结果不自动重放。提供中文失败提示，不向用户透传微信凭证诊断内容。

已有账号在个人资料中绑定微信核验手机号后，同步已匹配的社群身份与一次性会员权益，手机号占用或社群身份冲突拒绝写入。未更改支付、审核与入群规则。

审核路径：我的 → 个人资料 → 选择头像、填写昵称 → 绑定手机号 → 保存资料 → 返回并重新进入。也可在注册弹层填写资料后使用社群同步入口，确认登录成功后不再循环提示注册。

真实手机号授权需要用户在微信内点击，测试不伪造授权码或替用户创建微信身份。开发版上传不代表提交审核或发布。
