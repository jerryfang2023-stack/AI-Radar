# 1.1.4 融资下架与缓存更新修复

修复融资记录下架后列表仍显示旧数据、进入详情后出现空白页的问题。数据刷新允许审核下架导致的记录数减少，同时保留清单与索引数量、版本、日期的一致性校验。启用新版融资缓存；详情与主体缓存按最新可展示记录清理。下架详情返回融资列表并提示。

离线包同步已审核公开投影：2026-09-21 共 342 条，中国 89 条、全球 253 条。该数量是本次构建快照，后续以线上最新审核数据为准。

审核语（可直接填写）：
本次修复融资列表缓存更新问题，使已下架记录及时从列表移除，并优化下架详情返回流程，避免出现空白页面。同步更新已审核的融资数据，完善列表与详情展示一致性。

验证路径：打开融资首页，分别切换中国、全球并下拉刷新；查看有效融资详情后返回。通过历史分享链接打开已下架记录时，应提示下架并返回融资列表。注册、会员与支付流程未调整。

工程验证：npm run verify，157 项测试通过，25 个页面包校验通过。包括记录数量减少、旧缓存隔离、删除详情缓存、清单校验失败保留已接受版本，以及下架详情返回行为。

根因：旧版将记录数少于内置数量视为数据回退，拒绝更新，导致列表旧缓存与服务端详情审核状态不一致。这次需要升级小程序客户端；只更新服务器数据不足以修复旧版判断。上传开发版不代表提交审核或发布，由管理员提交审核。
