# V1.0.1 阅读优化与融资类别筛选

## 实现前的排版与文案约定

| 位置 | 字号 / 行高（rpx） | 配色与作用 | 文案 |
|---|---|---|---|
| 报告标题 | 44 / 64 | 深海军蓝，衬线字体 | 保留原标题 |
| 摘要 | 28 / 48 | 海军蓝底、暖白文字、金色标签 | 标签「本期摘要」，保留摘要 |
| 一级章节 | 34 / 50 | 金色章号、海军蓝标题、细分隔线 | 保留原章号和标题 |
| 二级标题 | 30 / 46 | 海军蓝、加粗 | 保留原小标题 |
| 正文 / 列表 | 28 / 50 | 深灰正文、短前置标签加粗 | 保留正文，不生成新结论 |
| 表格字段卡 | 26 / 44 | 暖白卡片、浅金表头、灰色字段名 | 仅原表格字段和值 |
| 日期 / 来源计数 | 22 / 34 | 中灰，辅助信息 | 保留日期、窗口和原计数 |

仅周报/月报使用新阅读样式；社群文章保留原排版。沿用服务端授权正文，不打包付费正文，不改动注册、分享或返回导航。无法安全对应表头的旧表格保留原文显示。

版本号及埋点版本同步为 1.0.1。保留全球排除中国、隐藏机器人融资、国内公司简称等已接受行为。

融资搜索同一行增加原生类别选择器（24rpx 字号，94rpx 高，244rpx 宽），默认「全部类别」，选项来自当前市场已有类别，可叠加关键词；不新增分类栏。切换市场后，如原类别不存在则回到全部类别。

## 验收路径

生态 → 行业观察 → 周报 / 月报：检查封面摘要、章节与条目层级、长正文换行和表格；分享直达检查底部四栏导航；游客超出试读后检查标题摘要仍可见、正文仍受权限保护。

运行 `npm run verify`；微信开发者工具编译和模拟器视觉检查。上传仅创建微信开发版，由负责人提交审核及发布。
