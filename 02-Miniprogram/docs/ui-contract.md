# 方案 2 UI 与文案契约

## Typography-first

| 位置 | 字体 | 字号 / 行高 | 字重 | 用途 |
|---|---|---:|---:|---|
| 页面主标题 | 中文衬线回退（Songti SC） | 40rpx / 56rpx | 600 | 融资终端、市场概览 |
| 公司名称 | 系统无衬线 | 32rpx / 44rpx | 600 | 列表与详情主识别 |
| 金额 | 系统等宽回退 | 36rpx / 44rpx | 500 | 列表核心数字 |
| 卡片标题 | 系统无衬线 | 28rpx / 40rpx | 600 | 详情分区与指标 |
| 正文 | 系统无衬线 | 26rpx / 42rpx | 400 | 公司介绍、信号与风险 |
| 标签/辅助信息 | 系统无衬线 | 22–24rpx / 34rpx | 500 | 轮次、日期、地区、状态 |

## Copy-first

| 页面 | 主文案 | 核心动作 | 空状态 |
|---|---|---|---|
| 融资终端 | 已发布融资情报 | 筛选、选择比较、复制导出 | 暂无符合条件的融资 |
| 融资详情 | 融资事实与证据 | 收藏、复制来源 | 暂无已公开内容 |
| 市场 | 当前公开样本概览 | 按市场类别进入终端 | 暂无统计数据 |
| 观察 | 我的观察列表 | 取消收藏、打开详情 | 还没有收藏融资 |
| 比较 | 公司融资比较 | 复制比较摘要 | 至少选择 2 家公司 |
| 我的 | 数据与本地设置 | 清空本地收藏 | 不适用 |

## Visual rules

- 页面底色 `#FFFDF8`，重点表面 `#FFFFFF`，局部纸色 `#F7F4EF`。
- 墨蓝 `#071827` 用于主操作与金额；金色 `#C8A766` 只用于选择态和证据入口。
- 已核验状态使用 `#2F8C57`；风险提示使用 `#B85C5C`。
- 公司无公开 Logo 时使用中性首字母标识，不抓取或虚构图标。
- 页面不展示模型来源、自动发布门禁、内部实体关联覆盖或数据中心链接。
