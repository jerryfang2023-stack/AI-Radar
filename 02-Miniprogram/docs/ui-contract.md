## Copy-first

| 页面 | 主文案 | 核心动作 | 空状态 |
|---|---|---|---|
| 融资情报 | 已发布融资情报 | 筛选、选择比较、复制导出 | 暂无符合条件的融资 |
| 融资详情 | 融资事实与证据 | 收藏、复制来源 | 暂无已公开内容 |
| 生态图谱 | 企业库 / 投资机构 / 核心人物 | 搜索企业、产品、机构、已投公司、人物、职务或赛道 | 暂无匹配结果 |
| 观察 | AI 商业变化周报与月报 | 切换周期、查看全文、进入收藏 | 暂无往期报告 |
| 我的收藏 | 当前设备收藏的融资 | 取消收藏、打开融资详情 | 还没有收藏融资 |
| 报告全文 | 本期研究判断与证据边界 | 阅读、分享 | 报告不存在 |
| 比较 | 公司融资比较 | 复制比较摘要 | 至少选择 2 家公司 |
| 我的 | 个人资料、行为与成长 | 查看浏览/收藏/关注、做任务、兑换权益、邀请好友 | 尚无行为记录 |
| 资料设置 | 微信资料与手机号 | 选择头像、填写昵称、申请手机号授权 | 微信号不可读取 |
| 成长与权益 | 体验积分账本 | 完成任务、兑换可落地权益 | 尚无积分记录 |
| 浏览记录 | 最近查看的融资 | 返回详情、清空记录 | 还没有浏览记录 |
| 我的关注 | 关注融资主题 | 关注/取消关注 | 尚未关注主题 |

## Visual rules

- 页面底色 `#FFFDF8`，重点表面 `#FFFFFF`，局部纸色 `#F7F4EF`。
- 墨蓝 `#071827` 用于主操作与金额；金色 `#C8A766` 只用于选择态和证据入口。
- 已核验状态使用 `#2F8C57`；风险提示使用 `#B85C5C`。
- 公司无公开 Logo 时使用中性首字母标识，不抓取或虚构图标。
- 页面不展示模型来源、自动发布门禁、内部实体关联覆盖或数据中心链接。
- 个人中心沿用“成长任务中心”原型：身份区、成长卡、三项行为统计、任务、权益、邀请与资料入口自上而下排列。
- 积分在没有服务端账本前明确标注为本地体验积分；邀请点击不直接发放积分，手机号授权码不落本地存储。
- 微信头像使用 `chooseAvatar`，昵称使用 `type="nickname"` 输入；微信号不提供读取或伪授权入口。
- “观察”第三栏只展示已发布周报与月报；融资收藏迁移到“我的收藏”，并从融资情报和个人中心进入。
- 报告卡片显示周期、证据窗口、摘要和事件/观点/社群计数；不显示模型来源、内部证据 ID 或生产字段。
