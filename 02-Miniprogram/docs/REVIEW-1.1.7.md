# 1.1.7 统一阅读权限

审核语：优化社群阅读流程，已登录且阅读权益有效的用户可查看分享实录、成员图谱、积分榜和 Token 权益，无需单独申请社群访问权限；移除原社群申请页面及相关引导。融资首页“今日融资精选”更名为“融资精选”。“我的”页面将邀请好友任务合并至成长任务，好友完成首次注册奖励 300 积分；新增当前页 7 天／30 天阅读权益积分兑换，删除重复邀请卡片及“全部权益”入口。本次调整不改变支付方式与费用。

体验路径：登录注册 → 社群 → 造浪者计划／分享实录、角色图谱、积分榜、Token 权益。有效内测阅读账号可直接浏览，不要求已入群身份。未登录或阅读权益到期时，使用统一会员中心。个人社群档案仅真实成员可编辑；成员手机号、微信号等非公开字段不随阅读响应返回。老申请链接只返回社群首页。

服务端：网关验证统一会员/试用阅读有效期，然后以仅内部可用的 reader 标记调用成员服务。普通读者没有虚构社群成员 ID、个人社群积分或 Token 奖励。社群成员资格、写权限和积分归属继续独立核验。

验证：小程序 167 项测试和 25 页面校验通过；账号服务 93 项测试、成员服务 99 项测试通过。覆盖无社群身份的阅读会员、到期拒绝、客户端伪造 viewer/reader 无效、非公开字段及写入保护。自动化环境未提供可用的原生截图工具，未声称完成本次真机视觉验收。

开发版上传后由管理员提交审核，上传不等于审核通过或正式发布。

补充验证：兑换取消、积分不足、未登录和服务端失败不产生本地授予；确认前后连续点击只发出一次请求。权益状态和积分余额均以服务端兑换响应更新。
