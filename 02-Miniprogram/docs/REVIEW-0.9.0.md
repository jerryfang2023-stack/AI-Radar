# 微信小程序 V0.9.0 审核说明

历史草案，已由 [V0.9.1 审核说明](REVIEW-0.9.1.md) 替代；下文首页排期/积分摘要描述不适用于本次发布。

## 版本更新说明

本次从线上 V0.8.3 升级社群栏目。新增造浪者计划的分享排期和完整分享实录、Founder 悬赏令、全员积分榜与积分规则、成员行业图谱与通讯录，以及“我的档案”查看和二次编辑。融资、生态和“我的”原有功能保持不变。

## 审核功能说明

小程序第三个底部栏目为“社群”。未加入社群的用户可以正常浏览社群首页，包括本周分享、最近实录、悬赏令摘要、行业图谱成员预览和积分摘要。用户主动点击子栏目、内容详情、成员档案或参与操作时，才会出现“申请加入”提示，不会在页面加载时自动要求授权。

已加入社群的用户可查看完整排期与分享实录、浏览并回答悬赏令、登记参加社群共创、查看全员积分榜和个人积分记录、查看积分规则、浏览行业角色图谱与成员通讯录，并在“我的档案”修改公开资料。

## 审核路径

1. 打开小程序，点击底部“社群”。
2. 查看开放的社群首页。
3. 点击“造浪者计划”“悬赏令”“积分榜”或“行业图谱”。未入群账号会显示申请加入提示。
4. 点击“申请加入”，可进入原生申请表；不会跳转外部网页。
5. 已入群账号可直接进入上述子栏目并验证完整详情与互动流程。

## 隐私与数据说明

- 社群公开目录仅展示成员主动填写并同意公开的姓名、城市、公司/项目、身份、行业、AI 实践方向、项目介绍、可交流能力和当前诉求。
- 手机号、微信号和内部审核信息不会进入行业图谱或通讯录，也不会打包在公开成员数据中。
- 手机号仅在用户主动申请或关联已有会员身份时使用，由现有账号服务处理。
- 未入群用户不会在打开社群首页时被强制授权或自动注册。

## 建议填写的审核备注

本版本重点升级原生社群栏目。审核人员可直接从底部“社群”进入开放首页；点击任一子栏目或详情会按社群身份显示申请加入提示。若使用已入群测试身份，可继续验证完整排期/实录、悬赏令、积分榜、积分规则、行业图谱、通讯录及“我的档案”编辑。所有页面均为微信小程序原生页面，无外部 H5 跳转；成员联系方式和内部审核信息不公开。
