# 小程序 1.1.0 审核说明

## 可粘贴审核语
本次更新优化生态栏目，将“行业观察”调整为“生态名录”，新增公司、产品、投资机构及人物分类检索，支持中国/全球市场切换、赛道筛选和关联档案浏览；保留生态图谱，新增对象关注及动态更新提示，优化下拉刷新与资料展示。内容用于 AI 行业信息查询，不提供证券交易、募资或投资收益承诺。

## 验收路径
1. 底部“生态”→“生态图谱 / 生态名录”：图谱保持趋势展示；名录四类入口、市场切换与搜索同一行。
2. 名录→公司/产品/投资机构/人物：关键词、市场、赛道（产品为场景）组合筛选；滚动分页；产品进入所属公司，公司进入旗下产品。
3. 对象详情→关注；“我的”→“我的关注”：查看分类关注及有更新状态。新关注不计入历史未读，打开受保护的完整融资动态后才标记已读。
4. 游客可浏览列表、名称及摘要；沿用跨栏目的单篇试读与会员权限。注册入口由用户主动操作；取消后保留预览。

本次仅上传微信开发版，由负责人提交审核与发布。
