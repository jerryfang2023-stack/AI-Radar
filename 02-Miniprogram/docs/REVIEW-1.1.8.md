# 1.1.8 融资分类与资本流向

资本流向、赛道热度榜、月度热图及赛道详情统一使用 AI-FUNDING-TAGS-1.0 的细分赛道。内置融资快照同步已审核的新目录；实时 manifest、索引与缓存校验分类版本和主/细分赛道关系，旧缓存或损坏缓存不能替换新分类数据。网络失败保留最近一次通过校验的新分类快照。

统计按独立融资事件去重，排除晚于统计日期的记录；全球与中国继续各自统计。最热与热图按近六个自然月、升降温按最近 90 天与此前 90 天的事件占比计算，金额不参与这些按笔数的排名。

体验路径：生态 → 生态图谱 → 全球/中国 → 赛道热度榜 → 赛道详情；重进页面和下拉刷新应保持当前市场选择。布局、支付与会员权限不变。

上传开发版不代表管理员已提交审核、微信已审核通过或已正式发布。

融资分类分支验证：171 项小程序测试通过；合并后验证另行记录。新增旧标签伪装成新版本、同版本损坏缓存重取、已审核删减、统计去重与未来日期截断回归。原生工具验收与上传结果单独记录，不由本地测试推定。
# 1.1.8 机构与人物档案

机构/人物详情增加来源核验的简介、基本资料、公开职务、职业与教育经历、发展历程、公开案例和公开联系方式。字段按已披露资料展示，无资料时不推断。

生态名录从线上档案清单检索历史档案；中国、全球分区保留，新增明确的“全部”选项。完整详情沿用现有游客试读、注册和会员权限；来源链接可复制。

验收路径：生态 → 搜索 → 投资机构/人物库 → 全部 → 搜索已研究对象 → 查看档案。直接分享、游客第二次详情、过期会员、身份切换、网络失败须保持现有权限和重试行为。

上传开发版、提交审核、审核通过及正式发布分别记录。服务器档案更新不等于客户端已发布。
