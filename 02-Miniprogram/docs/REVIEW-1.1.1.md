# 小程序 1.1.1 审核说明

## 可粘贴审核语
本次更新已移除“悬赏令”模块，包括发起、回答、共创及相关页面和入口，原审核反馈中的“发起一个悬赏令”功能不再包含在本版本。修复已注册用户浏览内容时被错误提示再次注册的问题，优化微信登录状态恢复与浏览权益提示。保留融资情报、生态图谱、生态名录及社群内容服务。

## 本机验证与验收路径
- 小程序 `npm run verify`：144 项通过，25 个页面，59 个 JS 文件。
- 服务端 `pytest -q`：78 项通过。验证过期签名凭证 + 同一微信身份恢复成功；篡改凭证和其他微信账号不能续期；续期不创建用户或赠送权益。
- 小程序并发测试覆盖会员信息与内容同时过期、一次恢复重试、切换账号后的迟到响应和写请求、网络失败不清空已有身份、社区缓存随同账号续期保持一致。
- “社群”保留造浪者计划、积分榜、Token 权益和角色图谱；全包无悬赏令页面及导航。
- 已注册且权益有效：分别打开融资详情、公司/产品/投资机构/人物档案、赛道详情、文章及比较页，不出现重复注册提示。
- 已注册但浏览权益到期：提示“浏览权益已到期”，点击进入会员中心；不会重复注册或自动获得新试用期。
- 登录状态需要恢复：自动核验同一微信账号，失败时保留预览并提供重新登录；“我的”不再以缓存资料冒充账号状态同步成功。
- 游客仍可浏览列表及一篇完整试读，第二篇保留注册选择；不会自动弹出注册。

微信原生 preview 编译成功。开发工具自动化截图连接失败；已对实际 WXML 权限提示与 WXSS 做 320/390 宽浏览器渲染检查，无横向溢出，该证据不等于真机截图。上传后请负责人复核实际账号与微信原生显示，再提交审核。

本次只上传开发版，不自动提交审核或发布。上传与服务部署的实际回执见对应 `releases/1.1.1/` 发布记录。
