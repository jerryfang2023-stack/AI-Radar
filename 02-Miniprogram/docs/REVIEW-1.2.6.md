# 1.2.6 审核说明

优化融资精选，结合时效、产品进展及公开投资观点展示优质融资信息，支持卡片滑动与详情查看；完善内容更新、市场分类和过期内容处理，提升浏览体验。

## 验收路径

融资首页 → 全球／中国切换 → 精选卡片滑动 → 点击详情。精选名单来自已审核的服务端规则，最多三条；每个市场独立排序，同企业与同子赛道不重复，未达到门槛时不凑数。观察保留有来源的机构署名或明确事实限制。日期显示融资披露日。

断网时可展示仍在有效区间内的包内快照或本次会话已接受结果；空名单清空、过期区间不展示，网络错误不替换成未审核最新项目。进入首页重新请求文案及名单，前台停留到换日或置顶期限也更新。

客户端接入服务端选择结果；不改变普通融资列表、详情权限、会员方案及卡片样式。之后的评分、窗口、置顶与文案调整可通过服务端发布，无需因内容运营反复上传客户端。
