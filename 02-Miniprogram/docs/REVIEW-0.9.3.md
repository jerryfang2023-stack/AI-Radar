# 观澜 AI 0.9.3 审核与验收说明

基于已上传的 0.9.2（`e52824573ce2bd0473e28a4e68593bc497eb654c`）开发。只上传开发版，由负责人自行提交审核；不自动正式发布。

## 更新说明（可复制）

优化生态栏目数据同步，每次进入自动检查最新数据，支持下拉刷新，网络异常时保留已显示内容。修复周报、月报正文无法读取的问题，完善读取失败重试及注册后的正文加载。保持现有页面布局和配色不变。

如本次审核尚未包含 0.9.1/0.9.2，请合并使用 [0.9.1–0.9.2 审核说明](REVIEW-0.9.2-COMBINED.md) 中的功能介绍和审核路径，再附加本版更新说明。

## 本次修改与边界

- `onShow` 每次检查融资与观察版本清单，只有版本变化才下载新索引；重复并发请求合并。页面先显示本地摘要，不增加阻塞加载弹窗。
- 下拉刷新完成或失败均结束原生刷新动画；失败保留好数据，只在用户主动下拉失败时提示。
- 根据负责人最新反馈：页面既不显示系统检查日期，也不显示最新融资日期，生态 WXML/WXSS 与 0.9.2 完全一致。两个日期只在数据层区分。
- 八月月报根因：融资站不再生成公开付费报告正文后，受保护内容构建器仍尝试读旧公开目录，得到 `mini: null`。所有 13 篇周/月报均受影响。本版直接从受控 Markdown 生成小程序正文，只写入受保护包，保持服务端鉴权和公开 404 边界。
- 付费正文不写入小程序静态包，不改账号权益、积分、社群成员状态或数据库。
- 空正文视为读取失败，保留标题摘要并可重试；注册完成后再次向服务端读取，不在客户端直接解锁。

## 验收

1. 生态→融资→生态，多次返回均检查两类版本清单；同版本复用索引，保持市场/观察筛选。
2. 不结束进程，模拟次日远端版本变化后再次进入，读到新索引；失败保留原数据。
3. 生态下拉刷新，成功/离线都正常结束动画，不显示日期模块。
4. 生态→行业观察→月报→八月月报，可通过正常会员/试读权限阅读；重新打开七月月报及周报也可读取。
5. 原鉴权继续生效：无效凭据返回 401，静态付费正文地址保持 404。
6. 小程序全套测试、原生项目校验和融资站测试；上线后核验受保护正文、服务健康、上传回执。具体 Git 哈希及回执记录在工作区本版发布记录中。

## 排版检查

生态无新增文案/字号/样式。仅错误状态复用暖白/深蓝：提示 24rpx/36rpx、400；重试按钮 28rpx、600。正常文章排版不变。Typography QC 专用技能当前不可用，按已读品牌规范人工检查；不宣称另有技能验收。
