# 1.0.0 市场展示修复

沿用已指定的 1.0.0 版本号，修复包使用新的不可变提交和独立上传回执，不移动原有 miniprogram-v1.0.0 标签。

- 全球不包含中国，融资列表、生态统计与服务端赛道详情口径一致。
- 小程序隐藏产品分类为 robotic_system（机器人系统）的融资；原始事件和 PC 档案保留。
- 中国公司有原文明确简称时优先使用简称，全名保留用于检索。
- 纠正 6 条国内公司地区标记；同日同数量的修正也刷新融资缓存。

验收：融资全球/中国切换、生态排行榜和赛道详情均无交叉；机器人不出现在目录或旧分享详情；使用法定全名可以搜到简称卡片。上传不等于提交审核或正式发布。
