# 小程序 1.3.3 审核说明

优化观澜 AI 小程序的生态名录与融资详情。修正企业组建方误出现在人物库的问题，补充产品所属公司和赛道信息。产品档案按实际收录轮次显示关联融资，点击历史记录可查看对应轮次、披露日期、金额和来源。同步更新融资数据快照。

## 验收路径

- 生态 → 生态名录 → 人物库。搜索长江北斗数字产业有限公司和浙江百应科技，核对两家企业已从人物库移除。企业组建信息可从长江词元的企业档案查看。
- 生态 → 生态名录 → 产品 → 全球。搜索 Claude Platform (API)，打开产品档案中的关联融资，确认对应 Anthropic F 轮。
- 融资 → 搜索长江词元。确认天使轮金额为超过 3000 万元，打开详情核对披露日期和信息来源。
