# 观澜 AI 0.9.4 审核与验收说明

基于 0.9.3 的客户端修复。上传不代表审核通过或正式发布，提交审核及发布由负责人操作。

## 本版更新说明

修复社群首页分享实录和成员档案的跳转异常，完善无效链接处理，提升内容浏览稳定性。保留现有页面样式、会员权限、积分规则及数据，不新增用户资料采集或支付功能。

## 验收路径

1. 已入群账号进入「社群」，分别点击编辑推荐与四条往期实录，确认打开对应场次；与「造浪者计划 → 分享实录」进入的内容一致。
2. 点击首页成员头像，确认打开对应成员档案；与「角色图谱 → 通讯录」进入的档案一致。
3. 未入群账号仍可浏览社群首页；点击受限详情时继续使用原申请加入流程，不绕过服务端权限。
4. 编号缺失的详情链接显示链接无效，不再请求 `archives/undefined` 或误报已发布实录丢失。
5. 生态、融资、会员、积分和申请资料保持原有行为；首页不新增日期、排期或个人积分模块。

## 发布边界

- 本次仅更新小程序客户端，不改数据库、不恢复删除成员、不重新部署支付或会员服务。
- 新客户端通过现有构建脚本更新公开离线索引；受保护正文、完整成员档案仍按权限从服务端读取，不打包到客户端。
- 发布前核验：融资索引 282 条，无记录删除。报告索引保持已上线的 13 篇周/月报（截至 2026-08-29）；用 `75b25c46bd` 的已发布报告源通过原构建脚本重建，与原索引一致。新入库的 2026-08-31 周报暂不随修复包进入列表，因为核验时线上正文尚未部署；待既有报告发布流程完成后由远端索引同步。
- 如尚未合并提交此前功能升级，可附加 [0.9.1–0.9.3 合并说明](REVIEW-0.9.3-COMBINED.md) 的功能内容，但微信后台本次应选择 0.9.4。
