# 1.2.7 审核说明

优化融资及生态档案的数据加载效率，完善网络异常时的兼容处理，提升融资精选、机构和人物档案的浏览稳定性。

## 验收路径

融资首页 → 全球／中国切换 → 融资精选与列表 → 详情；生态名录 → 投资机构／人物库 → 档案详情。会员、社群、精选规则和原有界面保持一致。

客户端优先读取服务端声明的紧凑索引，解码后继续使用原有数据契约；网络错误、格式异常、版本或数量不匹配时尝试兼容索引。两个接口均失败时保留已接受数据，损坏数据不写入缓存。

包内融资与精选数据同步已发布的审核快照。本次不运行融资采集、模型审核或服务器发布。开发版上传不等于提交审核或正式发布，由负责人操作后续流程。上传后证据记录在 docs/releases/1.2.7/README.md。
