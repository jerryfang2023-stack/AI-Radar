# 1.1.6 精选标题与投资方观点

审核语：优化融资首页“今日融资精选”标题的金黄色样式，新增带机构署名的投资方观点摘要，内容来自公开披露资料；保持原卡片大小、市场切换、搜索、筛选及详情访问流程不变。

体验路径：融资首页 → 查看金黄色标题与 Ema 的 Creaegis 观点 → 切换中国/全球 → 点击卡片查看原有详情。没有审核观点的项目隐藏观察行，不再重复分类。观点从公开数据接口独立更新，不预取付费详情，不增加登录要求。

后台更新：融资站 `config/funding-featured-observations.json` 经校验生成 `/data/funding-featured.json`。客户端每次显示融资首页刷新，使用当前市场和当前索引匹配融资 ID；删除观点可撤回，失败不影响浏览。仅中文摘要、机构及公开来源进入公开文件。

上传开发版不等于提交审核或发布，由管理员提交审核。
