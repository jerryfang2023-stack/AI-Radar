# 微信小程序 V0.9.2 审核说明

## 可复制的版本说明

优化社群页面加载速度和切换体验，完善积分榜显示及角色图谱排序，同步成员状态。保留分享实录、悬赏令、积分规则、通讯录及个人档案功能。

## 可复制的审核备注

社群首页可公开浏览，包含编辑推荐、往期实录及成员摘要；无已发布悬赏时隐藏悬赏模块。完整实录、积分榜、角色图谱和个人档案按成员身份开放。悬赏问题与回答经后台人工审核后展示，积分不能充值、提现或转让。手机号、微信号和内部审核信息不公开。本次优化本地摘要与会话缓存，保留服务端身份校验和状态更新。

## 验证路径

1. 底栏进入社群，再切换至融资或生态后返回；已有首页内容保持可见，后台刷新无重复加载文字。
2. 社群进入悬赏令、积分榜或角色图谱，返回后再次进入；短期内复用当前会话的数据，首次慢网络显示占位，失败可重试。
3. 积分榜与本人积分详情：管理权限授分不参与排名，不展示其流水；正常社群与活动积分保留，不改变管理账号等级或钱包余额。
4. 角色图谱按实际公开成员数降序，默认人数最多的类别；当前为企业服务落地。退出社群的成员不在首页成员预览、通讯录、角色列表和积分榜展示。
5. 修改本人档案或提交悬赏、回答后，相关会话数据失效并重新同步；完整实录、本人档案和草稿始终按权限读取，不持久化缓存。

公开首页摘要仅保存五分钟兜底；受限列表仅在当前账号会话内短暂保留。切换账号、身份失效和写操作使缓存失效。未提供离线访问受限数据或绕过成员身份的路径。

测试受限流程需真实已审核入群且绑定核验手机号的账号。微信后台上传只是开发版，审核与正式发布由负责人操作。原有功能路径及人工内容审核边界见 `REVIEW-0.9.1.md`，旧版审核资料保留为历史记录。
