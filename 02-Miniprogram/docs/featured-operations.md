## 运营入口

在 Guanlan-Funding-Portal 仓库维护 `config/funding-featured-policy.json` 和 `config/funding-featured-observations.json`，详情见该仓 `docs/featured-selection.md`。日常融资发布自动完成评分、撰写和独立审核，材料不变时复用记录，失败不放行。无机构原话可按材料独立提炼编辑分析，署名观点必须绑定实际机构原话与来源。分数是编辑展示优先级，不是投资价值评级。

客户端读取 `/data/funding-featured.json` 的 entries 与 selection，每次进入首页刷新并按有效区间展示。空名单不以最新项目补位；网络失败保留仍有效的已接受结果，离线包也受时间范围约束。更新门槛、权重、窗口、置顶和观察只需发布服务端；布局、交互及解码逻辑变更需要新的客户端包。1.2.5 及更早客户端仍按原有选卡逻辑，只能更新文案。

2026-10-03 00:00 后回读的示例：中国区芯光界、弋途科技、亿格云；全球区 Osavul、Metaview、Flow Engineering。这是发布时快照，日期、评分和去重会使名单变化，不作为固定白名单。

## 接手与验证

后续发布先同步双方最新 main，保留 compactIndexPath 与 `/data/mini/domains/` 生成物。紧凑索引失败仍须回退旧融资和档案接口，不能删除旧端点迫使用户更新。仅合入代码不代表生成物已上线，只有回执与线上内容核验能确认部署。

服务端变更运行对应精选与发布测试，并核对公开和受保护内容回执。客户端打包按 [发布手册](release-runbook.md)同步线上融资和精选快照，再运行 `npm run verify`。不为文档整理运行生产采集或模型，也不重复上传已确认版本。

历史包体证据保留于 [1.2.6 上传记录](releases/1.2.6/README.md)。该记录中的 70 分、初始两条全球精选和当时 Portal 提交仅描述上传时状态；后续服务端运营状态以本文及 Portal 当前配置为准，不改写历史记录。
