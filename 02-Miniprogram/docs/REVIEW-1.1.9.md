# 小程序 1.1.9：生态图谱全赛道热力与趋势

基于已合并的 1.1.8 档案详情和融资标签体系开发。2026-10-02 用户确认 Demo，并要求本窗口开发小程序与融资网站 PC 版。

## 本次变化

- 生态图谱完整呈现 AI-FUNDING-TAGS-1.0 的 7 大赛道、45 子赛道；包括无收录的类目。
- 全球/中国、3/6 个月、月度热力/赛道趋势、笔数/当月占比切换；支持展开所有子赛道、52 项趋势选择及月份融资明细。
- 删除用户指定的四条辅助说明：点击大赛道展开子赛道、点击色块查看当月融资、星号月份未完整提示、合计单位提示。当前月未完整的统计解释只保留在折叠口径内。
- 数据截至日来自已发布快照，日期不固定；变化比较采用最近两个完整自然月。全球排除中国。融资明细复用原有受保护详情入口。
- 融资精选按当前市场展示最近三条融资（可跨日期），保留滑动切换及每张卡片的详情入口。观察文案更新保留当前滑动位置；不足三条按实际数量显示。生态名录、社群、我的沿用 1.1.8 功能。

## 统计与测试

核心模型 `miniprogram/utils/capital-map.js` 与 Portal `capital-map.js` 相同；使用已去重公开融资投影，再按卡片 ID 去重。以稳定父子 ID 校验标签，错配记录不塞进其他赛道。月份明细只展示公开摘要，点击进入 `pages/detail/index`，由现有服务执行游客试读/会员鉴权。

182 项客户端测试通过，25 页面、68 JS 校验通过。新增全分类、零数据、市场隔离、重复/未来/无效日期、跨年、闰年月末、部分月比较、占比分母和原生控件路由测试。网站另有两端统计一致性与 DOM 交互测试。

## 审核说明（可粘贴）

本次更新优化生态图谱，按 AI 融资新标签体系展示 7 大赛道及 45 个子赛道的月度热力和融资趋势，支持全球/中国、3/6 个月筛选、融资笔数与占比切换，以及赛道和月份融资明细查询。融资精选展示最新三条融资，支持左右滑动与点击查看详情；精简辅助文案，优化移动端排版及刷新体验。登录、会员权益及游客试读规则保持不变。

体验路径：底部「生态」→「生态图谱」→切换全球/中国→展开子赛道→切换热力/趋势→点击月份融资色块查看列表→点击融资查看详情。图谱首页无需登录，完整融资详情沿用既有游客试读及会员权限。
