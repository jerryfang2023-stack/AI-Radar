# 观澜 AI 0.9.1–0.9.3 合并审核说明

整理日期：2026-08-31。适用于微信后台开发版本 **0.9.3**；本文件为上传后的配套材料，不修改已上传源码。提交审核及正式发布由负责人操作。

## 版本更新说明（可直接复制）

本次更新升级社群栏目，新增分享实录、悬赏问答、积分榜及积分规则、角色图谱、通讯录和可编辑个人档案，完善成员资料与分享记录展示。将行业观察整合至生态栏目，优化社群首页布局、积分统计口径和成员分类排序。优化数据缓存与后台同步，减少重复加载提示；生态栏目支持进入时自动检查更新及下拉刷新。修复部分周报、月报正文无法打开的问题，完善读取失败重试。保持现有整体配色与导航样式不变。

## 审核备注

底部栏目为“融资、生态、社群、我的”。社群首页开放预览，展示编辑推荐、往期分享实录和成员摘要；仅在存在已发布悬赏时展示悬赏模块，首页不显示分享排期和个人积分。排期保留在“造浪者计划”内。

用户主动进入受限社群子栏目或详情时按成员身份开放内容或提示申请。已审核入群并完成账号关联的成员可查看完整实录、积分榜与规则、角色图谱、通讯录，并修改“我的档案”；自填资料与编辑整理的分享证据分开保存。

悬赏问题和回答经后台人工审核后展示，结算防止重复发放。积分为站内积分，不可充值、提现、转让或交易，不涉及现金悬赏。社群榜单排除管理权限授分，原钱包与管理权限保持不变。

生态中的行业观察提供周报、月报及社群精华。0.9.3 增加进入时的版本检查与下拉刷新，联网失败保留原内容；页面不增加系统检查日期或最新融资日期提示。正文读取继续执行服务端权限校验，失败可重试，未将受限全文或个人档案打入公开数据包。
