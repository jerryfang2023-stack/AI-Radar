# 小程序 1.3.0 发布审阅

## 变更范围

- 将小程序离线融资快照更新到 2026-10-09 已发布的数据：553 张主体卡、593 条融资事件、127 张中国市场卡，分类版本 `AI-FUNDING-TAGS-1.0`。
- 将离线融资精选快照更新到 553 条观察、37 个有效窗口。
- 版本从 1.2.9 依照进位规则升至 1.3.0。融资页面、权限、搜索和分类逻辑不变。
- 融资标题使用当前公开目录中的简称；完整公司名称仍保留在公司全称字段中。

## 数据来源与检查

- 数据来自融资站已发布清单与索引，不在客户端发布流程中重新采集或审核融资。
- `npm run build:data` 已成功生成融资和报告离线数据。
- `npm run validate` 已通过：覆盖 25 个页面、72 个 JavaScript 文件。
- 准备阶段未运行本地测试；上传前在同一接受提交的完整工作树补跑 223 项测试，全部通过。PR #1237 的 Linux/Windows CI 均通过；独立上传归档的 367 个文件逐一匹配 Git blob。
- 微信开发者工具于 2026-10-09 明确返回 `√ upload`，包体 1,934,386 字节。上传记录见 [1.3.0 上传记录](releases/1.3.0/README.md)。新增文档不是上传包源码，上传仍绑定 `2f8617a3e4bd655b6b1eed94777aa668609a81a0`。

## 1.2.9—1.3.0 合并审核语

本次版本优化融资、生态和社群内容的加载稳定性，修复报告列表与详情在刷新、切换时可能出现的内容不一致，并完善异常缓存的恢复。同步更新融资及精选内容，优化部分企业名称展示，保留完整名称搜索和历史融资查询。体验路径：进入“融资”查看及搜索企业；进入“生态”浏览企业、机构与人物；进入“社群”阅读分享内容。可先浏览列表及公开预览，完整内容按既有登录和会员权限访问。

1.2.9 已提交审核的状态由用户告知；1.3.0 尚不确认审核提交、审核通过或正式发布。真机视觉与性能验收仍待体验。
