Why Vapi Partners with Quantstruct to Engage its Developer Community with Evergreen Docs
January 15, 2025
Vapi, founded by Jordan Dearsely and Nikhil Gupta, is mission-driven to become the world's leading developer platform for building voice AI agents. Vapi serves as critical infrastructure for discerning engineers, fast-growing startups, and innovative enterprises. Great, up-to-date documentation is essential for cultivating its developer community.
“Our docs are an extension of our product — it's how we build and maintain trust with self-service developers and enterprise customers. Our docs are also a significant competitive advantage for us as developers bet on a platform to build on.”
Vapi is backed by Bessemer Venture Partners, Abstract Ventures, AI Grant, Y Combinator, Saga Ventures, Michael Ovitz, and others.
Challenge
Vapi prides itself on shipping features daily and cultivating a vibrant ecosystem of developers and partners. As an API and SDK-centric product, Vapi depends on developers understanding various request and response details to build successful integrations. As a hypergrowth startup, Nikhil experienced “burning pain” in helping Vapi's self-service and enterprise customers build impactful voice agents. He wanted to do more to educate Vapi's community about new capabilities the team shipped daily, but was held back from serving Vapi's developers and driving adoption:
Time-consuming change management
As new dashboard features or API capabilities became available, Nikhil and the Vapi team had to scan recent GitHub pull requests and OpenAPI spec changes, take screenshots and construct API paths, then paraphrase these changes in a way that was actionable to developers integrating with Vapi.
Documentation struggled to stay updated
Frequent updates meant new features and fixes weren't always communicated in time, or at the quality that developers required to self-serve. Existing tutorials & guides would also go out of date with inaccurate references or stale links. Developers found it hard to keep up, increasing support load.
Fragmented publishing workflows
Even though Vapi's OpenAPI spec and open source SDK libraries serve as its single source of truth, the manual effort to prepare and update integration guides for each feature meant that every community update had to be manually drafted, reviewed, approved in GitHub, and separately distributed to its Slack and Discord channels—leading to inconsistencies, delays, and duplicate effort.
Generative AI and existing tools fall short
Nikhil had already tried various tools and traditional generative AI models to prepare changelogs and short guides for Vapi's customers. Besides being prone to hallucinations or creating unhelpful summaries, no traditional generative AI solution could:
Prepare paths to different API parameters reliably
Test API paths and code snippets for correctness
Update broken links
Take the necessary screenshots to illustrate a dashboard update
Improve over time to match Vapi's style
Solution and Benefits
After onboarding to Quantstruct's agentic documentation workflow platform, Vapi now saves many valuable hours every week writing docs. Quantstruct automatically manages 100% of Vapi's changelogs and change management docs updates, evaluates and self-improves to match Vapi's brand and style (while maintaining 100% accuracy on example code generated), and centralizes docs workflows to Slack and GitHub to free up engineering time to improve the platform:
Automated change detection and validated updates
Quantstruct's AI workflows automatically detect web dashboard & API changes, searches existing knowledge bases for more context, validates updates with single purpose agents and evaluations, then drafts developer-friendly updates in seconds.
Centralized publishing workflows via GitHub & Slack
Vapi configured Quantstruct to automatically open a GitHub pull request almost daily with suggested documentation updates. Once notified and approved through Slack, the updates are instantly published to Vapi's documentation site.
White-glove onboarding & support
From day one, Quantstruct provided hands-on migration and automatically tuned the underlying AI models to capture Vapi's style and industry accessibility guidelines. They also developed helpful capabilities like embedded screenshots, giving developers helpful guidance with no additional work from Vapi's side.
Foundation for an effective writing culture
As Quantstruct's agentic workflows improve and provide increasingly personalized drafts of updates to be reviewed, Vapi's product and engineering teams spend less time crawling through apps and copy-pasting repetitive content, and more time planning and designing developer relations content at a higher level.
