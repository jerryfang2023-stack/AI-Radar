# Unity中国发布团结引擎2.0，AI Agent"团结Codely"与百度智能云合作落地私有化AI Coding

## clean_text

7月28日，Unity中国发布团结引擎2.0，围绕核心引擎能力、跨平台部署、AI原生架构三大方向升级，其中可独立执行游戏开发任务的AI Agent"团结Codely"正式亮相。该Agent覆盖代码搜索、代码生成、IDE智能编辑等能力，基于百度百舸AI计算平台和昆仑芯P800等异构算力完成私有化部署验证，支持GLM、Kimi等开源模型推理适配，实现数据不出内网、模型服务可控的AI研发产线。
