# 争夺印度开发者市场：Cursor 推出月付 649 卢比 Start 套餐

## clean_text

IT之家 7 月 28 日消息，人工智能编程助手开发商 Cursor 今日宣布面向印度开发者推出 Cursor Start 个人方案。
这一方案含税价格为每月 649 印度卢比 （现汇率约合 45.5 元人民币） ， 基本上是 20 美元 （现汇率约合 135.5 元人民币） 标准方案价格的 1/3 。
Cursor 表示印度已是其全球第三大市场 ，过去一年内 Cursor 印度客户增长到了原来的三倍，印度的高级用户数量也高于世界上任何其他市场。
Cursor Start 套餐为印度付费用户带来了充足的 Cursor 模型访问权限、比免费方案更多的智能体请求次数始终运行的云端智能体、iOS 版 Cursor 应用程序和 Cursor 与工作流的集成。
