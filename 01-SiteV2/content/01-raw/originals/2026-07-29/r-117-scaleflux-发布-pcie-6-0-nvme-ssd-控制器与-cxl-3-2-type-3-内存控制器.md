# ScaleFlux 发布 PCIe 6.0 NVMe SSD 控制器与 CXL 3.2 Type 3 内存控制器

## clean_text

IT之家 7 月 28 日消息，存储和内存解决方案企业 ScaleFlux 美国加州当地时间今日发布了其 PCIe 6.0 NVMe 固态硬盘控制器（主控）FC6116 和 PCIe Gen6 / CXL 3.2 Type 3 内存控制器 MC600，进一步扩展了其高性能产品组合。
FC6116 支持 1×4 与 2×2 两种端口配置，顺序读取速率至高可达 28GB/s、顺序写入速率至高可达 25GB/s、4KB 随机读取至高可达 7000K IOPS，稳态 4KB 随机写入超 1000K IOPS，活动功率＜9W。
其适配 SLC / TLC / QLC NAND 闪存，容量可达 256TB，支持 EDSFF E1.S/ E1.L/ E3.S/ E3.L 和 U.2 / U.3 外形规格。
FC6116 专为大规模 AI 存储部署而设计， 提供完整的 PCIe Gen6 ×4 带宽和优秀的能效 ，带来更高的存储密度和更低的 TCO。
另一方面， MC600 这款 CXL Type 3 内存控制器基于 PCIe Gen6 PHY（物理层）并符合 CXL 3.2 规范，在 PCIe Gen6 x8 配置下典型功耗低于 9W。
其支持 2DPC 四通道（每通道 40-bit）DDR5、2DPC 双通道（每通道 72-bit）DDR4，兼容 RDIMM 与 UDIMM 内存模组， 配合 DDR5 能实现至高 2TB 的容量 ，支持 PCIe AIC、EDSFF E3.S 等外形规格，计划 2026Q4 出样。
