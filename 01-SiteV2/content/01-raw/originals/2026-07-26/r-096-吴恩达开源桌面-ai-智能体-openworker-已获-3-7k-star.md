# 吴恩达开源桌面 AI 智能体 OpenWorker，已获 3.7k Star

## clean_text

IT之家 7 月 25 日消息，吴恩达（Andrew Ng）昨日（7 月 24 日）在领英（LinkedIn）发布动态，宣布推出开源 AI 智能体 OpenWorker， 不仅满足聊天交互，还能高效完成用户交代的任务。
在运行平台上，适用于苹果 macOS 的 OpenWorker 已经上线，Github 页面显示 Windows 版已支持运行，但尚未签名。
OpenWorker 基于 Ng 的 aisuite 库构建，这是一个与提供商无关的 Python 框架，通过统一 API 支持多种大型语言模型。
功能方面，吴恩达表示 OpenWorker 可以帮用户润色文件，准备客户简报、梳理日程、起草报告或处理 Slack 警报。它可以在你的文件和日常工具中运行，生成所需成果，并在执行任何重要操作前进行检查。
在模型调用方面，OpenWorker 并不捆绑模型，用户可以使用 GPT 5.6 Sol、Claude Fable、Gemini 3.6，以及包括 Kimi、GLM、DeepSeek、Inkling 在内的开源 AI 模型，并支持 Ollama 等本地 AI 模型。
吴恩达，图源：WikiMedia IT之家发稿前，访问 GitHub 项目页面，OpenWorker 目前已收获 3.7k Star。Star 是 GitHub 平台上的核心功能，类似于社交媒体的“点赞”或浏览器的“收藏夹”。
用户点击仓库右上角的 Star 按钮即可标记喜欢的项目，方便日后在个人主页查找，同时它也是衡量开源项目受欢迎程度与质量的重要指标。
