# Runta｜2000万美元｜种子轮

> [!summary] 公司概况
> Runta 是一家为 AI 智能体构建执行层基础设施的初创公司，通过隔离沙箱、访问控制、支出上限和审计日志等机制，帮助企业“像养育孩子一样”管理和约束自主运行的 AI 智能体，防止其造成破坏或产生失控的账单。

## 资本判断

> [!analysis] 应用层判断
> 资本押注的核心变量是：AI 智能体从“回答问题”转向“自主执行动作”后，运行时控制层将从可选的附加组件变为生产部署的前提条件。本轮融资以超过 1 亿美元的估值完成，依赖的已验证信号包括：创始人 Guanlan Dai 在 Cloudflare 和 Kong 的基础设施背景、a16z 合伙人 Martin Casado 明确提出的“智能体需要一台计算机”的系统软件叙事，以及企业市场对智能体授权、访问治理和监督的同步需求爆发。但证据边界仅限于早期风险投资信号和行业趋势判断，尚未包含可验证的企业收入或大规模生产部署数据。

### 已验证信号

- 创始人 Guanlan Dai 曾担任 Cloudflare 边缘团队技术负责人和 API 公司 Kong 的核心代理构建者，具备深厚的基础设施背景。
- a16z 合伙人 Martin Casado 公开提出“智能体需要一台计算机”的系统软件叙事，并指出智能体繁荣正导致 CPU 短缺。
- 同一时期多家智能体基础设施初创公司（Arcade.dev、1Password/Apono、Atomicwork）获得融资或进行收购，表明企业市场对智能体控制层的需求正在集中爆发。

### 证据边界与风险

- Runta 的护栏产品可能成为昂贵的中间件，如果仅附着于现有工作流而非改变工作流本身，企业可能选择从已掌握工作流的平台采购更便宜或更集成的控制方案。
- 早期风险投资需求尚未转化为可验证的持续性企业收入，生产部署和重复采购行为才是类别持久性的真正证明。

### 投资机构公开理由

#### Andreessen Horowitz (a16z) · Martin Casado · a16z 合伙人

a16z 认为 Runta 不是又一个沙箱云，而是为智能体从零重建的核心系统软件，并指出智能体繁荣正导致 CPU 短缺，需要新的基础设施。

> Casado argues this is not “yet another sandbox cloud” but core systems software rebuilt for agents. He also flags an odd side effect of the agent boom. A CPU shortage now sits alongside the model-driven GPU crunch, because agents need a lot of ordinary compute.

## 同类对照

### Arcade.dev

- **产品/方案**：智能体授权平台
- **场景**：企业 AI 智能体的授权与权限管理
- **目标客户**：部署 AI 智能体的企业
- **融资概况**：6000万美元 A 轮融资
- **核心差异**：Arcade.dev 专注于智能体授权，而 Runta 聚焦于智能体执行层的计算基底，提供隔离沙箱和支出上限等运行时控制。

### 1Password (收购 Apono)

- **产品/方案**：AI 智能体访问治理
- **场景**：AI 智能体访问凭证与权限治理
- **目标客户**：使用 AI 智能体的企业
- **核心差异**：1Password 通过收购 Apono 进入智能体访问治理领域，侧重于凭证管理；Runta 则从操作系统层面为智能体提供完整的执行环境。

### Atomicwork

- **产品/方案**：AI 劳动力治理平台
- **场景**：企业 IT 环境中 AI 劳动力的监督与治理
- **目标客户**：企业 IT 部门
- **核心差异**：Atomicwork 面向企业 IT 的 AI 劳动力治理与监督，Runta 则提供底层的智能体执行运行时，强调隔离和资源控制。
