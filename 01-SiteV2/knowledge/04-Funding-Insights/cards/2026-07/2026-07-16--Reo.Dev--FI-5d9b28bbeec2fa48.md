# Reo.Dev｜1130 万美元｜A 轮

> [!summary] 公司概况
> Reo.Dev 是一个面向工程和技术团队的 AI 原生 GTM 平台，通过分析开发者活动信号（如 GitHub 提交、CLI 使用、文档互动等）来识别购买意图，帮助软件公司将开发者行为转化为销售管道。

- **本轮金额**：1130 万美元

- **公布日期**：2026-07-16

## 产品

### Reo.Dev 平台

AI 原生 GTM 平台，通过捕获开发者活动信号（GitHub 提交、CLI 使用、包安装、文档互动等）和第三方技术情报，帮助销售、市场和 RevOps 团队识别高意图的技术买家并优先推进商机。

- **目标客户**：面向工程和技术团队销售的软件公司
- **关键能力**：
  - 开发者意图信号捕获
  - 开发者知识图谱（超 1 亿工程师画像）
  - 账户去匿名化
  - 买家预测
  - 技术图谱分析
  - 细分与漏斗优先级排序
  - 营销活动管理
  - 开发者社区监听
  - 职位变动追踪

### Agent Intent Gateway

捕获 AI 代理通过 MCP 协议与产品交互时产生的购买意图信号，将代理的评估行为（如阅读文档、调用 API、运行 CLI）转化为可操作的管道信号。

- **目标客户**：面向工程团队销售且希望捕获 AI 代理购买信号的软件公司
- **关键能力**：
  - 捕获 AI 代理的 MCP 交互
  - 追踪代理询问内容、时间和所属账户
  - 将代理评估行为转化为管道信号

## 资本判断

> [!analysis] 应用层判断
> 资本押注的核心变量是：软件采购正从“人驱动”转向“开发者行为驱动”并进一步迈向“AI 代理驱动”，而传统销售情报工具无法捕获这一层的信号。Reo.Dev 的 1 亿+ 工程师知识图谱和 900 亿+ 意图信号构成了数据护城河，Agent Intent Gateway 则是对代理驱动采购的前瞻布局。本轮融资的验证信号包括：200+ 客户中涵盖 NVIDIA 等头部技术公司，DataHub 单季度从平台信号生成 101 万美元管道，Unstructured.io 40% 管道来自平台识别账户，且部分投资机构本身就是客户。但当前代理驱动评估仅占管道的一小部分，其规模化时间表尚不确定；平台依赖的公开数据源可能面临隐私合规风险；通用销售情报巨头若大举投入开发者意图领域，可能挤压垂直玩家的空间。

### 已验证信号

- 开发者知识图谱超 1 亿工程师画像，覆盖 3000+ 技术和 250+ 技术职能
- 超 200 家付费客户，包括 NVIDIA、LangChain、ElevenLabs 等头部技术公司
- DataHub 单季度从平台信号生成 101 万美元管道
- Unstructured.io 40% 交易管道来自平台识别账户，会议预订量提升 20%
- 部分投资机构在投资前已是平台客户，用自己的管道验证了产品价值

### 证据边界与风险

- 代理驱动评估目前仅占客户管道的一小部分，Agent Intent Gateway 的商业化规模和时间表尚未验证
- 平台依赖 GitHub、Stack Overflow 等公开数据源，数据可访问性和隐私合规政策变化可能影响数据供给
- ZoomInfo、6sense 等通用销售情报巨头若大举投入开发者意图领域，可能凭借现有客户基础和资本优势挤压垂直玩家

#### Elevation Capital · Krishna Mehra and Poorvi Vijay · Elevation Capital 投资人

AI 公司越来越多地向工程师和 AI 代理销售，两者都需要高度上下文化的互动而非通用销售策略；Reo.Dev 在超 1 亿工程师画像的数据层上构建了品类领先的平台，为软件和基础设施公司创造了有效销售所需的上下文与行动系统。

Reo.Dev has built a category-leading platform on a data layer of more than 100 million engineer profiles, creating the System of Context and Action that software and infrastructure companies will increasingly rely on to sell effectively.

## 同类对照

### Common Room

- **产品/方案**：Common Room 平台
- **场景**：通过 GitHub 和社交媒体活动识别用户意图
- **目标客户**：面向开发者的软件公司
- **核心差异**：Common Room 帮助分析 GitHub 和社交媒体活动，但不捕获开源使用信号（如安装或 CLI 命令）；Reo.Dev 专注于捕获开发者行为信号（CLI 运行、Docker 拉取、包安装等）并构建开发者知识图谱。

### Warmly

- **产品/方案**：Warmly 平台
- **场景**：基于公司意图数据的销售信号
- **目标客户**：B2B 销售团队
- **核心差异**：Warmly 基于更广泛的公司意图数据提供信号；Reo.Dev 专注于开发者和工程团队产生的购买信号，而非通用公司意图数据。

### ZoomInfo

- **产品/方案**：ZoomInfo 平台
- **场景**：通用 B2B 销售情报和公司数据
- **目标客户**：B2B 销售团队
- **核心差异**：ZoomInfo 提供通用公司数据和传统 B2B 销售情报，但无法捕捉开发者购买行为的细微差别；Reo.Dev 通过分析公共代码仓库、开发者论坛和包管理器的数据来识别技术购买意图。

### 6sense

- **产品/方案**：6sense 平台
- **场景**：通用 B2B 收入情报和意图数据
- **目标客户**：B2B 销售和市场团队
- **核心差异**：6sense 提供通用收入情报和意图数据；Reo.Dev 专注于开发者和技术买家意图，通过分析 GitHub、Stack Overflow 等开发者平台上的行为信号来识别购买意图。

### Apollo.io

- **产品/方案**：Apollo.io 平台
- **场景**：通用 B2B 销售互动和情报
- **目标客户**：B2B 销售团队
- **核心差异**：Apollo.io 提供通用销售互动和情报工具；Reo.Dev 专注于开发者和技术买家意图，通过分析开发者活动信号而非通用公司数据来识别购买意图。
