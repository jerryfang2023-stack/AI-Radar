# Orthogonal｜$4.3M｜种子轮

> [!summary] 公司概况
> Orthogonal 正在构建面向 AI 代理的发现、编排与支付层，使代理能够实时发现所需能力、编排工作流并完成支付，从而自主完成复杂任务。

## 融资概览

- **融资轮次**：种子轮
- **本轮金额**：$4.3M
- **累计融资**：$4.3M
- **公布日期**：2026-06-23

### 投资方

- **Pantera Capital** — 本轮领投
- **Blast** — 本轮参投

## 公司与团队

- **公司**：Orthogonal
- **总部**：San Francisco, California
- **官网**：[orthogonal.com](<orthogonal.com>)
- **团队规模**：2（2026-06-26）

### 创始团队

- **Christian Pickett** — Co-founder
- **Bera Sogut** — Co-founder

## 产品

### Orthogonal API 网关与支付层

为 AI 代理提供统一的 API 发现、访问和支付网关，使代理无需单独管理凭证、账户或订阅即可按需调用数百个 API，并按使用量付费。

- **目标客户**：AI 代理开发者、AI 原生初创公司、GTM 团队
- **关键能力**：
  - 统一 API 发现与访问
  - 按使用量付费，无需订阅或销售沟通
  - 支持 MCP 服务器和 SDK 集成
  - 支持传统法币、x402 和 MPP 等多种支付通道
  - 单一密钥替代数十个 API 密钥

## 客户与应用

- **Runtype** — AI 产品平台；将 Orthogonal API 作为原生工具集成到 Runtype 平台中，使开发者无需管理密钥即可在构建 AI 工作流时调用 100 多个 API。

## 关键指标

- **已集成 API 合作伙伴数量**：35+（2026-06-25）
- **已命名 API 合作伙伴数量**：30+（2026-06-23）
- **员工人数**：2（2026-06-26）

## 资本判断

> [!analysis] 应用层判断
> 本轮融资的核心押注变量是 AI 代理从辅助工具转向自主执行商业交易时，是否需要一套全新的、非人类原生的 API 发现与支付基础设施。Pantera 的领投并非基于当前收入或用户规模，而是直接执行其 2026 年 2 月发布的《代理商业的金融轨道》论文，该论文预测 AI 代理将在 2030 年中介 3 至 5 万亿美元的全球消费商业。Orthogonal 的估值信号尚未公开，但 430 万美元的种子轮规模与两人团队、无公开收入的状态相匹配，投资方的集中度（AI×加密专项基金）表明这是一次高度主题化的早期押注，而非基于广泛市场验证的分散投资。

### 已验证信号

- 产品已上线生产环境，支持 35 个以上 API 合作伙伴，包括 Apollo、People Data Labs、Coresignal 等
- 已与 Runtype 达成合作，将 Orthogonal API 作为原生工具集成到其 AI 产品平台中
- 创始团队具备 Coinbase 支付、Vercel 计费、Google reCAPTCHA 和 Maps API 以及 Amazon Robotics 的复合背景
- 已支持多种支付通道，包括传统法币、x402 和 MPP，并正与 Stripe 的 Privy 和 Tempo 团队合作

### 证据边界与风险

- 自主代理商业仍处于预测阶段，而非可观测的经济活动流；Pantera 的 3 至 5 万亿美元预测指向 2030 年，距当前仍有四年，市场需求尚未被实际交易量验证。
- 团队仅两人，尚无公开收入，产品执行能力与规模化速度存在高度不确定性。
- 竞争格局并非空白：Fetch.ai 已运营代理间代币经济，Linux Foundation 的 Agent2Agent 协议提供了开放标准框架，大型平台可能在封闭生态内解决发现、路由和结算问题，削弱开放协议的市场空间。
