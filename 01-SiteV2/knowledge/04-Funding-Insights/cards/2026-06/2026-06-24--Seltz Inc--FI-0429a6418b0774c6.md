# Seltz Inc.｜$12.5M｜种子轮

> [!summary] 公司概况
> Seltz 是一家智能体基础设施初创公司，构建专为 AI 代理优化的网络搜索基础设施。公司拥有完整的搜索技术栈，包括爬虫、索引、检索模型和排序系统，旨在为 AI 代理提供结构化、可引用的机器可读结果，而非传统的链接列表。

## 产品

### Web Knowledge API

一个为AI系统提供实时、上下文工程化网络数据的API，返回经过筛选、过滤和排序的结构化内容，专为LLM、AI代理和RAG管道设计。

- **目标客户**：构建AI系统的团队，包括LLM应用、RAG管道和自主代理的开发者
- **关键能力**：
  - 拥有完整搜索技术栈（爬虫、索引、检索模型、排序）
  - 返回结构化、机器可读的结果（文本、表格、图像）
  - 每日抓取数亿页面，延迟低于200毫秒
  - 上下文工程化：评分段落并提取代理所需的确切内容

## 资本判断

> [!analysis] 应用层判断
> 资本押注的核心变量是：AI代理作为搜索消费者的范式转变，需要从底层重建网络检索基础设施，而非在现有搜索引擎之上封装。Seltz 的已验证信号包括：1）创始人 Antonio Mallia 在信息检索领域的深厚学术和工业背景（NYU博士、Amazon AGI团队、Pinecone研究科学家）；2）团队拥有多名信息检索博士和Amazon AI研究老兵；3）已交付可用的平台（8个月内从新闻索引起步）；4）自有基准测试显示89%准确率和低于250毫秒延迟；5）已获得一家基础实验室合同并运行多个试点。然而，Seltz 的融资规模（1250万美元）远低于竞争对手 Parallel（1亿美元）和 Exa（2.5亿美元），且团队仅15人，在资本密集型的网络搜索领域面临显著资源劣势。当前估值或融资所依赖的信号主要来自团队技术深度和早期产品交付能力，而非规模化商业验证。

### 已验证信号

- 创始人 Antonio Mallia 拥有信息检索博士学位，曾任职于 Amazon AGI 团队和 Pinecone
- 团队包含多名信息检索博士和 Amazon AI 研究团队前成员
- 自建完整搜索技术栈（爬虫、索引、检索模型、排序），不依赖 Google/Bing API
- 平台在8个月内从新闻索引起步并完成交付
- 自有 Dynamic News Search 基准测试显示89%准确率，延迟低于250毫秒
- 每日抓取数亿页面，返回结果延迟低于200毫秒
- 已获得一家基础实验室合同，并与多家构建智能体工作流的公司进行试点

### 证据边界与风险

- 资本劣势显著：Seltz 种子轮仅融资1250万美元，而竞争对手 Parallel 已融资1亿美元（估值20亿）、Exa 融资2.5亿美元，在资本密集型的网络搜索领域面临巨大资源差距
- 团队规模极小：仅15名员工（约一半为全职），在需要大规模工程投入的网络搜索基础设施建设中可能面临执行瓶颈
- 基准测试非独立评估：89%准确率和延迟数据来自自有基准测试，缺乏第三方验证，可能无法反映真实生产环境表现
