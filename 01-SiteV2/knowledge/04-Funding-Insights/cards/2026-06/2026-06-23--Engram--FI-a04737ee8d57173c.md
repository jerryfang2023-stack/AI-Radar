## 产品

### Learned Memory Layer

Engram 训练模型预先研究组织环境，将大量组织知识压缩为紧凑、可复用的模型记忆，使模型在推理时无需重复处理相同上下文，从而大幅降低 token 消耗。

- **目标客户**：中大型知识型组织、企业 SaaS 平台、法律与专业服务公司、大型企业团队
- **关键能力**：
  - 将组织知识压缩为紧凑、可复用的模型记忆
  - 使用 1% 到 10% 的 token 即可匹配或超越前沿模型
  - 记忆随使用时间持续改进
  - 客户拥有自己的记忆数据

## 资本判断

> [!analysis] 应用层判断
> 资本押注的核心变量是企业 AI 部署中因无状态推理导致的 token 成本失控问题。Engram 以 13 人团队获得 9800 万美元融资和 6 亿美元估值，依赖的已验证信号包括：与 Microsoft、Notion、Harvey 的生产级合作测试；创始团队来自 Stanford、Berkeley、Cornell 的顶尖记忆与持续学习研究者；CTO 的 Cartridges 方法已在 2025 年 6 月发表为学术论文。但 100 倍 token 效率声明尚未经独立基准测试验证，且公司仅有 8 个月历史和 13 名员工，企业级规模部署的可行性仍待证明。

### 已验证信号

- 与 Microsoft 合作在 Microsoft 365 中测试记忆层，并获得 Dapple 和 Azure 的 GPU 容量承诺
- Notion 在其自定义代理中测试 Engram 模型，已观察到 token 用量降低一个数量级
- Harvey 正在将 Engram 技术应用于法律 AI 工作流
- 创始团队包括 Stanford 教授 Chris Ré 和 Scott Linderman，以及 Cartridges、Active Reading 等记忆相关研究的核心作者

### 证据边界与风险

- 100 倍 token 效率声明尚未经独立第三方基准测试验证，可能仅适用于特定工作负载而非通用场景
- 前沿模型提供商可能在 12-24 个月内将类似记忆层功能原生集成到 API 中，削弱 Engram 的差异化优势
- 13 人团队和 8 个月的公司历史意味着企业级规模部署、安全合规和客户支持能力尚未得到验证

## 同类对照

### Mem0

- **产品/方案**：结构化记忆平台
- **场景**：多会话聊天机器人、面向客户的代理个性化
- **目标客户**：需要结构化记忆和实体关系的开发者
- **核心差异**：Mem0 提供结构化记忆存储与检索，而 Engram 训练模型学习组织上下文并将其压缩为可复用的内部状态，而非仅作为外部存储。

### Zep

- **产品/方案**：时序上下文图记忆系统
- **场景**：跟踪事实随时间变化的对话代理
- **目标客户**：需要持久化用户记忆的 AI 应用开发者
- **核心差异**：Zep 使用时序上下文图跟踪事实变化，属于存储与检索类方案；Engram 则通过训练模型内化组织知识，减少对检索的依赖。

### Letta

- **产品/方案**：分层记忆代理运行时
- **场景**：需要操作系统式分层记忆的自主代理
- **目标客户**：构建有状态 AI 代理的开发者
- **核心差异**：Letta 在代理运行时内提供操作系统风格的分层记忆系统，属于存储架构创新；Engram 则通过预训练压缩记忆，使模型本身具备组织知识。
