## 产品

### Checkpoints

一个开源的命令行工具，可自动捕获 AI 智能体的编码上下文，包括推理、提示和决策，并将其与每次 Git 提交关联。

- **目标客户**：使用 AI 编码智能体的开发者
- **关键能力**：
  - 自动捕获 AI 智能体会话的完整上下文
  - 将上下文存储为与 Git 提交关联的结构化数据
  - 支持审查历史记录、导航智能体上下文和搜索 AI 贡献图

## 资本判断

> [!analysis] 应用层判断
> 资本押注的核心变量是软件开发生命周期从“人类手动编写”向“人类编排 AI 智能体舰队”的范式转移。本轮 6000 万美元种子轮融资及 3 亿美元估值，高度依赖创始人 Thomas Dohmke 在 GitHub 领导 Copilot 并将其扩展至超过 1.8 亿开发者的已验证履历，以及 Felicis 所称的“开发者工具史上最大种子轮”的稀缺性信号。判断的证据边界在于：目前仅发布了首个开源 CLI 工具 Checkpoints，支持 Claude Code 和 Gemini CLI，更广泛的平台尚未推出，产品市场匹配仍待验证。

### 已验证信号

- 创始人 Thomas Dohmke 曾担任 GitHub CEO，领导 Copilot 成长为数十亿美元业务，并将平台扩展至超过 1.8 亿开发者。
- 已发布首个开源产品 Checkpoints，支持 Anthropic 的 Claude Code 和 Google 的 Gemini CLI。
- 种子轮融资 6000 万美元，估值 3 亿美元，被 Felicis 称为开发者工具史上最大种子轮。

### 证据边界与风险

- Entire 目前仅发布了一个开源 CLI 工具，其核心的 git 兼容数据库、通用语义推理层和 AI 原生用户界面等平台组件尚未交付，产品愿景与当前可交付成果之间存在巨大差距。
