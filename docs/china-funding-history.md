# 2026 年国内 AI 融资历史补采

授权范围：2026-01-01 至 2026-09-12 的中国区 AI 融资。按月、按国内来源检索；媒体所在地、索引摘要与搜索日期仅用于发现线索。最终原文日期、中国区主体、融资事实及实体关系仍通过各自证据门禁。

用户在 Spark 对比完成后明确改选 Terra：本次结构化提取和失败重试显式使用 `gpt-5.6-terra`（medium），通过本机 Codex 登录执行，不导出登录凭据。Astra 仅负责配置与异常处理；网络采集、去重、月份覆盖和确定性门禁由脚本执行，不逐条调用 Astra。模型提议保留实际 model、原文哈希及逐字引用；失败留在 QA，不能凭模型输出自动合并实体。日常监测的模型配置独立保留。

本机执行 `node --env-file=<已有密钥文件> agent-workflow/tools/run-china-funding-pipeline.mjs --date=2026-09-12 --history-from=2026-01-01 --history-to=2026-09-12`。Terra 只处理授权国内原文；保留已验收候选，新增提议记录实际模型。云端不持有 Codex 登录，只能复用已保存的提取结果；缺少提取结果时停止事实阶段，不能回退 Flash 或假报完成。翻译和下游融资卡独立保留既有 DeepSeek 配置。

云端检查点与发布入口：`.github/workflows/china-funding-history-pr.yml`，输入 `from`、`to`、采集日期 `date`，失败恢复传 `resume_run_id`。脚本 `collect-china-funding-history.mjs` 为每个来源/月执行复杂和简化两类查询，逐查询检查点保存后复用。首轮 252 次查询获得 221 条去重候选，其中一次请求失败；这不是完整案例总数或市场覆盖率。

按用户要求，以同一组 20 篇原文比较 Flash 与 GPT-5.3-Codex-Spark（low），每请求 4 篇、字段定义及引用约束一致。Flash 全字段约束通过 15/20，Spark 9/20；Spark 未达到预先设定的至少 19/20 且零不受引用支持字段的切换门槛，当时保持 Flash；随后用户明确选择 Terra，此旧对比报告不代表 Terra 的测评结果。Flash 一批两次 JSON 解析失败，4 篇缺少输出；另有 7 个引用/字段不匹配。Spark 有 23 个引用/字段不匹配和 1 篇输出缺失。门禁通过率不是事实准确率；值的写法不同也会降低模型间一致率。报告与样本来源元数据位于历史目录，全文、提示及模型完整回复只保存在仓库外私有目录。本次没有启用 Spark 全量采集。

历史目录为 `agent-workflow/reports/china-funding-history/<from>_<to>/`，与每日目录分开。原文仍只进入私有证据库；事实写入实际采集批次，同时保留原始披露日期。批次内的 `historical-funding-authorization.json` 限定允许超过日常三个月窗口的国内 SourceArtifact ID 和日期范围，后续重建继续读取该授权，不会将未授权来源一并扩展。历史健康数据单独保存，不替换每日国内质量快照。

采集、模型提取、共享库写入、融资卡生成、部署各有独立结果。完整收录与新增卡数只能在原文、主体和应用门禁通过后报告。`npm run test:china-funding` 覆盖月份边界、历史授权范围、中文披露日期、检查点复用与 Flash 重试选择。
