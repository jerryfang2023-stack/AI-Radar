# 中国区融资实体同步 · 2026-09-12

国内融资卡已有公司和人物资料，但正式实体库未完成相应审核准入。本次复用历史补采的已接受 Claims 和私有原文，完成公司身份审核、人物证据重放、正式档案及融资应用关联同步。

| 项目 | 结果 |
| --- | --- |
| 正式公司总数 | 218 → 320，新增 102 家 |
| 正式人物总数 | 61 → 222，新增 161 位 |
| 正式投资机构总数 | 1,844，全部有证据；更新投资活动与公司关联 |
| 中国区来源公司 ID | 133 个：130 个关联到 118 家正式公司，3 个待核验 |
| 人物—公司候选 | 193 条：177 条归并为 161 位人物，16 条待核验 |
| 融资卡 | 400 → 396；中国区 144 → 140，海外 256 不变 |

公司简称、全名和重复 ID 按证据归并。智推时代建立独立公司 ID，修复其融资卡误用百川智能 ID 的问题；昂听融资定位到经营公司听象科技，不将产品品牌直接作为法律实体别名。同名人物按已审核公司 ID 匹配，避免跨公司误关联。法定代表人、首席科学家和创始团队成员保留各自证实的职责，不统一称为创始人。

融资卡的身份归并保留原始来源事件；人物档案解析到归并后有效卡片 ID。融资应用引文只支持人物档案与应用引用，不直接生成规范创立或任职关系。

公司待核验：智子芯元的登记名称差异、OdyssLife 的已接受 Claim 未命名公司、华深智药与实际融资方 Earendil Labs 的主体区别。人物待核验包括不可重放的来源、公司身份冲突及仅能证实技术来源而不能证实任职的条目。逐条原因见 `china-funding-entity-review-decisions.json` 和 OPS 国内公司与人物库同步面板。此结果不表示所有历史融资线索均已完成事实核验。

新增审核门禁检查候选处置是否闭合、正式公司是否存在、人物引文及其哈希是否完整，并支持在私有原文库逐字重放。后续国内融资 Skill 要求在提取后执行正式实体准入审核，区分卡片聚合资料和正式档案。

验证：全部历史融资卡门禁（107 个日期文件）、实体历史/目录、机构库、私有引文重放及分类一致性；相关融资、实体与 OPS 桌面/移动端浏览器回归。公开网站、Mini Program 数据及受保护 OPS 的部署回执保存在外部工作交付目录。
