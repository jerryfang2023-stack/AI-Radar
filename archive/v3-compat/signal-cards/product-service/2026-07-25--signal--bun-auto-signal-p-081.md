# Claude Code 整合 Rust 重构版 Bun，Linux 启动快 10%

## 新闻事实

Bun 是执行 JavaScript 和 TypeScript 的 Runtime，此前开发者耗时 11 天、耗费 16.5 万美元将其从 Zig 重写为 Rust。

## 原文要点

- 耗费 16.5 万美元，已重构 JavaScript 运行时 Bun
- 开发者贾里德 · 萨姆纳（Jarred Sumner）宣布在 Claude Fable 5 模型的帮助下， 耗时 11 天、耗费 16.5 万美元，已重构 JavaScript 运行时 Bun，从 Zig 完全重写为 Rust 语言 。
- 其中出现“Bun v1.4.0”字样，以及大量带“.rs”扩展名

## 价值描述

此前开发者耗时 11 天、耗费 16.5 万美元将其从 Zig 重写为 Rust。

## 可见原文片段

Bun 是用于执行 JavaScript 和 TypeScript 程序的 Runtime，Claude Code 虽以独立可执行文件形式分发，但其程序底层使用 Bun 作为运行环境。
