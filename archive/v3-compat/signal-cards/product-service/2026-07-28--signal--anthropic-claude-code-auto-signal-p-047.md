# Perplexity 发布 pplx：单二进制 CLI 工具，将 Search API 带入终端供编码智能体使用

## 新闻事实

Perplexity 发布 pplx，一个官方命令行客户端，提供 `pplx search web` 和 `pplx content fetch` 两个命令，输出单一 JSON 对象。

## 原文要点

- 支持 macOS arm64 和 Linux，并附带适用于 Claude Code
