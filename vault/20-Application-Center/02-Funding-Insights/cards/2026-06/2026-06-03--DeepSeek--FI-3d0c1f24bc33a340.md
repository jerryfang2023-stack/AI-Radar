# DeepSeek｜约74亿美元（约500亿元人民币）｜首次外部融资轮

> [!summary] 公司概况
> DeepSeek是一家中国人工智能研究实验室，以开源权重模型和极高的成本效率闻名，其V3和R1模型曾以远低于西方实验室的训练成本实现接近前沿的性能。公司此前完全由创始人梁文锋的量化对冲基金幻方量化资助，在2026年6月完成了首次外部融资。

## 产品

### DeepSeek V4-Pro

一个拥有1.6万亿总参数、490亿活跃参数的开源权重模型，支持100万token上下文窗口，采用混合注意力架构以大幅降低长上下文推理成本。

- **目标客户**：开发者和企业
- **关键能力**：
  - 100万token上下文窗口
  - 混合注意力架构

- **目标客户**：对成本敏感的开发者
- **关键能力**：
  - 100万token上下文窗口
  - 极低推理成本
  - 开源权重

## 资本判断

> [!analysis] 应用层判断
> 资本押注的核心变量是中国在AI前沿领域拥有一个不受西方资本控制的、具备国家战略意义的开源模型实验室。本轮融资的估值（520亿至590亿美元）并非基于其当前收入，而是基于其作为中国AI“国家队”的战略期权价值、极致的成本效率优势，以及通过开源策略对西方闭源模型定价体系的持续破坏力。已验证的信号包括：V4系列模型在多个基准上接近GPT-5.5和Claude Opus 4.7的性能，同时API价格仅为后者的几十分之一；V4-Flash连续三周位居全球模型调用量第一；公司已积累1.27亿月活用户。然而，这些判断的证据边界在于，公司的商业化路径尚不清晰，其开源策略直接限制了API收入的增长空间，且本轮融资的结构设计（外部投资者无投票权、五年锁定期）本身就反映了投资者对治理风险的妥协。

### 已验证信号

- V4系列模型在GPQA Diamond等基准上得分接近GPT-5.5和Claude Opus 4.7，但API价格远低于对手。
- V4-Flash连续三周位居OpenRouter全球模型调用量第一，周调用量达3.69万亿token。
- 截至2026年3月，DeepSeek月活跃用户数约1.27亿，5月网站访问量达5.41亿，中国排名第一。
- 公司在2025年实现了约4.7亿美元的净利润，而同期OpenAI亏损约50亿美元。
- 创始人梁文锋个人出资约29.4亿美元，占本轮融资的40%，显示其对公司的绝对承诺和控制力。

### 证据边界与风险

- 商业化路径不明确：公司向投资者承诺聚焦AGI研究和开源，而非短期商业化，其开源策略直接限制了API的直接收入潜力，高估值缺乏可验证的收入模型支撑。
- 人才流失压力持续：本轮融资的触发因素之一是核心研究人员被竞争对手高薪挖角，单轮融资无法从根本上解决人才保留问题。
- 地缘政治风险加剧：国家AI产业投资基金的参与强化了DeepSeek作为中国战略资产的属性，可能加速西方市场的禁令和限制，进一步压缩其海外商业空间。

## 同类对照

### Anthropic

- **产品/方案**：Claude Code
- **场景**：AI编程智能体，通过终端执行、文件I/O和工具调用来完成软件开发任务。
- **目标客户**：软件开发者
- **融资概况**：估值约9650亿美元

### OpenAI

- **产品/方案**：Codex
- **场景**：AI编程助手，为开发者提供代码生成和编辑功能。
- **目标客户**：软件开发者
- **融资概况**：估值约8520亿美元
- **核心差异**：OpenAI的Codex周活跃用户从300万增长到400万仅用了15天，显示出强大的用户基础；DeepSeek的Code Harness仍处于团队组建阶段。

### OpenAI

- **产品/方案**：GPT-5.5
- **场景**：通用前沿大语言模型，通过API提供付费服务。
- **目标客户**：开发者和企业
- **融资概况**：估值约8520亿美元
- **核心差异**：DeepSeek V4-Pro的API定价远低于GPT-5.5，缓存命中价约为GPT-5.5长上下文价格的1/14960；在GPQA Diamond基准上，V4 Pro得分90.1%，GPT-5.5得分93.6%。
