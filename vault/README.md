这是 WaveSight 唯一的生产 Obsidian Vault。数据中心保存事实型可读投影，应用中心保存基于 V4 证据生成的研究与应用内容；代码、原始证据、数据库和运行日志不进入本 Vault。

## 边界

- 数据中心不输出建议、价值判断或机会判断。
- 应用中心可以生成报告、融资研究、机会地图和变化雷达，但必须引用已接受的 V4 证据。
- 一线观点与社群情报是独立信息域，不能直接形成 Claim、CanonicalEvent 或 RELATION-V2.1。
- `99-Archive` 默认从 Obsidian 索引隐藏；历史恢复以 Git 为准。
